Elastic Compute Cloud, Instâncias e AMIs

1. Amazon EC2

Elastic Compute Cloud

"Computação redimensionável na nuvem. Facilita a escalabilidade para desenvolvedores."
  • Aluguel de Máquinas Virtuais (VMs): Chamadas de Instâncias.
  • Controle Total: Acesso Root/Administrator.
  • Flexibilidade: Mude CPU/RAM com alguns cliques (Stop > Change Type > Start).

Hypervisor gerencia múltiplas VMs em um hardware físico.

2. Tipos de Instância

Hardware otimizado para tarefas diferentes.

Família (Letra) Nome Foco (Use Case) Exemplo
T / M General Purpose Equilíbrio. Web Servers, Dev/Test. t3.micro (Free tier), m5.large
C Compute Optimized Processamento Bruto. HPC, Machine Learning, Games. c6g.xlarge
R Memory Optimized Muita RAM. Bancos de Dados, Cache (Redis). r6.large
Regra Mnemônica:
M (Main/Medium) | C (Compute) | R (RAM) | T (Tiny/Turbo)

2.1 Entendendo o Nome

m5.xlarge
  • m: Família (General Purpose)
  • 5: Geração (Hardware mais novo = nº maior)
  • xlarge: Tamanho (CPU/RAM)
Escala de Tamanho:
nano < micro < small < medium < large < xlarge < 2xlarge...

3. AMI (Amazon Machine Image)

É o "modelo" (template) usado para criar a instância. Contém:

  • Sistema Operacional: Linux (Ubuntu, Amazon Linux), Windows Server.
  • Aplicações Pré-instaladas: Wordpress, SQL Server, etc.
  • Permissões de Boot.
Você pode criar sua própria AMI (ex: "Servidor Web Configurado") para lançar cópias idênticas rapidamente (Auto Scaling).

4. Ciclo de Vida (Prática)

Running

Ligado.

Você é cobrado por segundo/hora.

Stopped

Desligado (Shutdown).

Não cobra CPU. Cobra disco (EBS).

Terminated

Destruído.

Disco apagado (normalmente). Irreversível.

Passo a Passo (Lab de Hoje):

  1. Acessar Console AWS.
  2. EC2 > Launch Instance.
  3. Escolher AMI (Ubuntu) e Tipo (t2.micro - Free Tier).
  4. Key Pair (Gerar .pem para acesso SSH).
  5. Launch!

Resumo

  • EC2 é o serviço básico de computação da AWS.
  • Escolha o Tipo certo para economizar dinheiro (não use C5 para um blog simples).
  • AMIs agilizam o deploy de servidores padronizados.
