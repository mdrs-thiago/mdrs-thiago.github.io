Virtual Private Cloud, Subnets e Segurança

1. Amazon VPC

Virtual Private Cloud

"Sua rede privada virtual isolada na nuvem pública."
  • Isolamento Lógico: Seus recursos não enxergam outras VPCs (por padrão).
  • Controle: Você define IPs, Subnets, Tabelas de Roteamento.
  • Escopo: Uma VPC vive dentro de uma Região (Ex: us-east-1).

2. Subnets (Sub-redes)

Divisões da VPC para organizar recursos e segurança.

Subnet Pública

Possui acesso direto à Internet.

Uso: Web Servers, Load Balancers.

Possui Route Table apontando para o Internet Gateway (IGW).

Subnet Privada

NÃO possui acesso direto à Internet (entrada).

Uso: Bancos de Dados, Backups.

Mais segura. Para sair pra internet, precisa de um NAT Gateway.

Uma Subnet reside em uma única Zona de Disponibilidade (AZ).

3. Segurança de Rede

O Firewall na Nuvem.

Security Groups (SG)

Firewall a nível de INSTÂNCIA (EC2).

  • Stateful: Se você permite a entrada (Inbound), a resposta (Outbound) é permitida automaticamente.
  • Regras: Apenas "Allow" (Permitir). Tudo é bloqueado por padrão.
  • Ex: Permitir Porta 80 (HTTP) de qualquer IP (0.0.0.0/0).

3.1 NACL (Opcional)

Network Access Control List

Firewall a nível de SUBNET.

  • Stateless: Precisa liberar entrada e saída explicitamente.
  • Permite regras de "Deny" (Bloquear IP X).
  • Atua como uma segunda camada de defesa antes do Security Group.
Para iniciantes: Foque no Security Group. Ele resolve 99% dos casos.

4. Cenário Prático (Lab)

  1. Criar uma VPC (Ex: 10.0.0.0/16).
  2. Criar uma Subnet Pública (10.0.1.0/24) e anexar Internet Gateway.
  3. Lançar EC2 na Subnet Pública.
  4. Configurar Security Group: Liberar portas 22 (SSH) e 80 (HTTP).
  5. Acessar via navegador e terminal.

5. Endereçamento IP

IP Privado

Fixo (enquanto a instância existir).

Usado para comunicação interna na VPC.

Ex: 10.0.1.5

IP Público

Dinâmico (muda se desligar a máquina).

Acessível da Internet.

Elastic IP (EIP)

IP Público Fixo/Estático.

Você "aluga" o IP. Útil para servidores que não podem mudar de endereço (DNS).

Resumo

  • VPC é sua casa na AWS. Defina quem entra e quem sai.
  • Subnets separam o que é Público do que é Privado.
  • Security Groups são o firewall obrigatório para qualquer servidor.
