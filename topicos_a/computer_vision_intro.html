Introdução à Visão Computacional Clássica

Ensinando as máquinas a "ver" com regras e filtros

O que é Visão Computacional?

  • É um campo da Inteligência Artificial que treina computadores para interpretar e compreender o mundo visual.
  • Usando imagens digitais de câmaras e vídeos, as máquinas podem identificar, classificar e reagir a objetos.
  • O objetivo final é permitir que as máquinas "vejam" o mundo de forma semelhante aos humanos.

A visão computacional permite que robôs identifiquem a bola e os outros jogadores.

O Desafio Fundamental: O "Abismo Semântico"

  • Para um computador, uma imagem é apenas uma grelha de números (pixels), onde cada número representa a cor e o brilho de um ponto.
  • Para um humano, uma imagem contém objetos, cenas e significados.
  • O grande desafio da Visão Computacional é transpor essa ponte: extrair um significado semântico de alto nível a partir de dados numéricos de baixo nível.

Para a máquina, esta imagem é apenas uma matriz de valores de cor.

Abordagem Clássica: Processamento de Imagem

  • As primeiras abordagens focavam-se em criar filtros manuais para detetar características.
  • Um filtro é uma pequena matriz de números (chamada de kernel) que desliza sobre a imagem.
  • A operação matemática de aplicar um filtro é chamada de convolução.
  • Diferentes kernels podem ser projetados para realçar diferentes aspetos da imagem.

Um kernel de Sobel, projetado para detetar bordas verticais.

A Operação de Convolução

  • O kernel desliza sobre cada pixel da imagem de entrada.
  • Em cada posição, é feita uma multiplicação elemento a elemento entre o kernel e a porção da imagem que ele cobre.
  • Os resultados dessas multiplicações são somados para produzir um único valor de pixel na imagem de saída.
  • Este processo é repetido para toda a imagem.

O kernel (vermelho) desliza sobre a imagem de entrada (azul) para criar o mapa de características (verde).

Domínio Espacial vs. Domínio da Frequência

  • Domínio Espacial: A filtragem é feita diretamente na grelha de pixels, como na convolução que vimos. É intuitivo e bom para efeitos locais.
  • Domínio da Frequência: A imagem é convertida para uma representação de frequências usando a Transformada de Fourier.
    • Baixas frequências correspondem a áreas suaves e de cor homogénea.
    • Altas frequências correspondem a bordas, ruído e detalhes finos.
  • Filtrar neste domínio significa simplesmente atenuar ou amplificar certas frequências.

Uma imagem (esquerda) e a sua representação no domínio da frequência (direita). O centro contém as baixas frequências.

Filtro Passa-Baixa: Suavização (Blur)

  • Um filtro "passa-baixa" atenua as altas frequências, resultando numa imagem mais suave.
  • É muito usado para reduzir ruído e detalhes indesejados.
  • O filtro mais comum é o Gaussian Blur, que usa um kernel onde os pesos seguem uma distribuição Gaussiana (dando mais importância ao pixel central).

Filtro Passa-Alta: Realce de Nitidez (Sharpen)

  • Um filtro "passa-alta" faz o oposto: ele amplifica as altas frequências, realçando bordas e detalhes.
  • Uma técnica comum é a "unsharp masking":
    1. Cria-se uma versão desfocada (blur) da imagem.
    2. Subtrai-se a imagem desfocada da original. O resultado é uma imagem que contém apenas os detalhes (as altas frequências).
    3. Adiciona-se esta imagem de detalhes de volta à imagem original, tornando-a mais nítida.

Segmentação por Limiarização (Thresholding)

  • É uma das formas mais simples de segmentação de imagem, o processo de dividir uma imagem em regiões.
  • O objetivo é criar uma imagem binária (preto e branco).
  • Escolhe-se um valor de limiar (threshold). Todos os pixels mais escuros que o limiar tornam-se pretos (0), e todos os mais claros tornam-se brancos (1).
  • É muito útil para separar um objeto do seu fundo.

Uma imagem em tons de cinza (esquerda) e o seu resultado binarizado (direita).

Refinamento: Morfologia Matemática

  • Um conjunto de operações baseadas em formas, geralmente aplicadas a imagens binárias após a limiarização.
  • Erosão: "Corrói" as bordas dos objetos brancos. É útil para remover pequenos ruídos (pontos brancos).
  • Dilatação: "Expande" as bordas dos objetos brancos. É útil para preencher pequenos buracos ou falhas nos objetos.
  • A combinação de erosão e dilatação permite operações de "abertura" e "fechamento" para limpar a imagem de forma robusta.

O efeito da dilatação e da erosão numa forma.

Extração de Características (Feature Extraction)

  • Após o pré-processamento, em vez de usar a imagem inteira, a abordagem clássica foca-se em extrair descritores numéricos que resumem o conteúdo da imagem.
  • Histogram of Oriented Gradients (HOG): Descreve um objeto pela distribuição da direção dos gradientes (bordas) dentro dele. Foi muito usado para deteção de pessoas.
  • Scale-Invariant Feature Transform (SIFT): Um algoritmo poderoso que encontra "pontos-chave" numa imagem e cria um descritor para cada um que é robusto a mudanças de escala e rotação.

Pontos-chave SIFT detetados numa imagem. Cada ponto tem um descritor associado.

Limitações da Abordagem Clássica

  • Fragilidade: Mesmo com descritores robustos como o SIFT, a abordagem é sensível a variações de iluminação, oclusão e deformações não rígidas.
  • Não Generalizam Bem: Um pipeline projetado para detetar rostos não funciona para detetar carros. Cada novo problema exige um novo projeto de engenharia de características.
  • Trabalho Intensivo: Projetar manualmente o pipeline de extração de características para cada problema é um trabalho imenso e impraticável em larga escala.
