Semantic Segmentation

Understanding the World at the Pixel Level

Thiago Medeiros

Universidade do Estado do Rio de Janeiro

1. Visualizing the Goal

Instead of drawing bounding boxes, we want the network to predict a dense Mask, identifying the exact class of every single pixel.

Input: RGB Image

Output: Binary Map

$1$ = Object, $0$ = Background

The "1 Million Classifiers" Analogy

If an image has $1000 \times 1000$ pixels, training a Segmentation Network is equivalent to training 1,000,000 tiny classifiers simultaneously in a single forward pass.

2. Types of Segmentation

It's important to distinguish between the three major sub-fields of image segmentation.

Semantic

Classifies pixels into broad categories (e.g., "Car", "Road", "Person").

All cars get the exact same mask color. It does not distinguish between Car 1 and Car 2.

Instance

Identifies each individual object of interest separately.

Car 1 gets a red mask, Car 2 gets a blue mask. (Typically ignores the background "stuff" like sky or road).

Panoptic

The ultimate goal. It combines both.

It distinguishes individual countable "things" (Car 1, Car 2) AND assigns a class to uncountable "stuff" (Road, Sky).

3. The Resolution Problem

Standard CNN architectures (like ResNet or VGG) were designed for Image Classification. They purposefully destroy spatial resolution to extract high-level semantic meaning.

Standard CNN (Classification)

  • Input: Image $256 \times 256$
  • Pooling: Reduces size repeatedly ($128 \to 64 \to 32...$)
  • Flattening: Destroys the grid completely.
  • Output: 1D Vector (e.g., $10$ classes)

We know it's a "cat", but we have no idea where the cat is anymore.

Segmentation CNN

  • Input: Image $256 \times 256$
  • Processing: Must retain/recover spatial details.
  • Output: A dense grid of exactly $256 \times 256$ pixels.

How do we map low-resolution semantic features back to a high-resolution mask?

Fully Convolutional Networks (FCNs)

The first major breakthrough (Long et al., 2015) was realizing we can simply throw away the Linear layers.

By replacing the final nn.Linear layer with a nn.Conv2d(kernel_size=1), the network never flattens the image. It outputs a spatial map (a "heatmap" of classifications) instead of a single vector.

1x1 Conv as a Spatial Classifier

4. The U-Net Architecture

Originally designed for Biomedical Image Segmentation (Ronneberger et al., 2015), it became the absolute standard for all segmentation tasks.

5. The Secret Sauce: Skip Connections

The Information Bottleneck

The Encoder compresses the image to capture deep semantic meaning (the "What"), but in doing so, it loses precise spatial boundaries (the "Where").

Upsampling from the bottleneck alone results in blurry, indistinct blobs.

The Solution

U-Net copies the high-resolution feature maps from the Encoder and concatenates them directly with the Decoder's upsampled features. This provides the exact local details needed to draw sharp borders.

Concatenation (`torch.cat`)

6. How to Upsample?

To construct the Decoder, we need to increase the spatial resolution (e.g., $32 \times 32 \to 64 \times 64$). We have two main options:

Option A: Bilinear Interpolation

Purely mathematical resizing (like enlarging an image in Photoshop). Averages nearby pixels to fill in the blanks.

nn.Upsample(
    scale_factor=2, 
    mode='bilinear'
)

Fast, no parameters, but not learned.

Option B: Transposed Conv

Also known as "Deconvolution". It is a convolution with learnable weights that expands the input instead of shrinking it.

nn.ConvTranspose2d(
    in_channels, out_channels, 
    kernel_size=2, stride=2
)

Standard in U-Net. Allows the network to learn *how* to best fill the gaps.

Code: Implementing a U-Net Block

How the Skip Connection is executed in the `forward` pass in PyTorch.

import torch
import torch.nn as nn

class UNetDecoderBlock(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        # 1. Aprender a aumentar a resolução (Upsample)
        self.up = nn.ConvTranspose2d(in_ch, out_ch, kernel_size=2, stride=2)
        
        # 2. Convoluções após a junção (in_ch duplo devido à concatenação)
        self.conv = nn.Sequential(
            nn.Conv2d(out_ch * 2, out_ch, kernel_size=3, padding=1),
            nn.ReLU(inplace=True)
        )

    def forward(self, x_decoder, x_encoder):
        # Passo 1: Aumentar o tensor que vem de baixo
        x_up = self.up(x_decoder)
        
        # Passo 2: O Segredo! Juntar com a feature map do Encoder (Dimensão 1 = Canais)
        x_cat = torch.cat([x_up, x_encoder], dim=1)
        
        # Passo 3: Passar o bloco misturado pelas convoluções
        return self.conv(x_cat)

7. Training & Loss Functions

Pixel-wise Cross Entropy

We calculate standard Cross-Entropy for every single pixel independently and average them.

The Imbalance Problem

If detecting a tumor that occupies 1% of an MRI, the model can achieve 99% accuracy by simply guessing "Background" for everything! CE struggles with this.

Dice Loss / Soft IoU

Optimizes the overlap directly, largely ignoring the massive background.

$$\text{Dice Score} = \frac{2 |A \cap B|}{|A| + |B|}$$ $$\text{Loss} = 1 - \text{Dice Score}$$

Works beautifully for highly imbalanced medical images and small objects.

Summary & Applications

Core Concepts

  • Semantic vs Instance: Pixels vs distinct objects.
  • FCNs: Discarding linear layers to preserve the 2D grid structure.
  • U-Net: Encoder compresses context; Decoder recovers resolution.
  • Skip Connections: Transfer high-res structural details directly to the decoder.
  • Dice Loss: Fights extreme class imbalance.

Real-World Applications

  • Medical Imaging: Tumour boundary extraction (MRI/CT).
  • Autonomous Driving: Delineating drivable area, sidewalks, and pedestrians.
  • Satellite/Agri: Calculating exact land use or deforestation area.
