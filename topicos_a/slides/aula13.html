2. Training: The "1 Million Classifiers" Analogy

Imagine your image has $1000 \times 1000 = 1,000,000$ pixels.

Training a Segmentation Network is like training 1 Million tiny classifiers at the same time.

  • Input: Pixel features (RGB + Context).
  • Target: Is this specific pixel a "Cat" or "Background"?
  • Loss: Sum of errors for all 1 million pixels.

2. The Resolution Problem

Standard CNN

  • Input: $256 \times 256$
  • Pooling: Reduces size ($128 \to 64 \to 32...$)
  • Output: Vector (Class Probabilities)

We lost the spatial detail!

Segmentation CNN

  • Input: $256 \times 256$
  • Processing: ???
  • Output: $256 \times 256$ (Mask)

We need to get the resolution back.

3. The U-Net Architecture

Designed for Biomedical Image Segmentation.

4. Training Segmentation

Pixel-wise Cross Entropy

We calculate the Cross Entropy Loss for each pixel independently and average them.

Problem: If 90% of image is background, the model learns to output "background" everywhere!

Dice Loss / IoU Loss

Optimizes the overlap directly.

$$ Loss = 1 - \frac{2 |A \cap B|}{|A| + |B|} $$

Works much better for imbalanced classes (small objects).

4. Skip Connections

The Secret Sauce

Upsampling (getting bigger) is blurry.

Solution: Copy the high-resolution feature maps from the Encoder and concatenate them with the Decoder upsampled features. 


class UNetBlock(nn.Module):
    def forward(self, x):
        # 1. Downsample
        x1 = self.conv1(x)
        x2 = self.pool(x1)
        
        # ... (Bottom) ...
        
        # 2. Upsample
        x_up = self.up(x_bottom)
        
        # 3. Skip Connection
        # Concatenate x1 (high res) with x_up
        x_cat = torch.cat([x1, x_up], dim=1)
        
        return self.conv_out(x_cat)

5. How to Upsample?

Option A: Bilinear Interpolation

Mathematical resizing (like Photoshop).

nn.Upsample(scale_factor=2, mode='bilinear')

Option B: Transposed Convolution

Learnable upsampling!

nn.ConvTranspose2d(...)

  • Has weights ($\theta$).
  • Can learn how to fill in the gaps optimally.
