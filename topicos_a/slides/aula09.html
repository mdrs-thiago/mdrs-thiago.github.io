Understanding Convolutions, Kernels, Padding, Stride & Pooling

1. Motivation

The "Old" Way (MLP)

Treats images as flat vectors.

  • Problem 1: Parameters. A 200x200 image has 40k pixels. A hidden layer of 1000 units needs 40 Million weights.
  • Problem 2: Spatiality. Flattening $2D \to 1D$ destroys the grid structure. Pixel $(0,0)$ becomes far from $(0,1)$ in the vector sense.

The CNN Solution

Designed for data with a grid topology (Images, Audio, Maps).

"We should process images locally, because nearby pixels are highly correlated."

2. The Convolution Operation

The core building block of Computer Vision.

Principle 1: Locality

We don't need to see the whole image at once to find an edge. We just need to look at a small window (e.g., 3x3 pixels).

Receptive Field: The area of the input image that a neuron "sees".

Principle 2: Stationarity

A "cat" is still a "cat" whether it's in the top-left or bottom-right.

Parameter Sharing: We use the same filter (weights) across the entire image. If it's useful here, it's useful there.

3. How Convolution Works

The Math

A Filter (Kernel) is a small matrix of learnable weights (e.g., $3 \times 3$).

We slide this filter over the input image. At each position:

  1. Overlay: Match filter weights with image pixels.
  2. Multiply: Element-wise multiplication.
  3. Sum: Add all results together + Bias.

$$ S(i, j) = \sum_m \sum_n I(i+m, j+n) \cdot K(m, n) $$

4. Padding

Why Pad?

  1. Preserve Size: Without padding, the image gets smaller every layer ($N-F+1$).
  2. Edge Info: Without padding, corner pixels are only used once.

"Same" Padding: Pad with zeros so Output Size = Input Size.

5. Stride

The "Step Size" of the sliding window.

  • Stride 1: Slide 1 pixel. High overlap.
  • Stride 2: Slide 2 pixels. Skips info. Halves the resolution.
Output Size Formula: $$ O = \lfloor \frac{W - K + 2P}{S} \rfloor + 1 $$

Downsampling

Using Stride > 1 is an alternative to Pooling for reducing spatial dimensions.

Modern architectures (like ResNet) often use Stride 2 in the first layer.

6. Pooling Layers

Making things manageable and robust.

Why Pool?

  1. Reduce Dimensions: Less memory, faster computation.
  2. Invariance: Small shifts in the input shouldn't change the classification.
  3. Increase Receptive Field: Higher layers see more of the original image.

Max Pooling (Most Common)

Take the maximum value in a local window (e.g. 2x2).
