Loss Functions & Evaluation Metrics

Measuring Success and Guiding Optimization

Thiago Medeiros

Universidade do Estado do Rio de Janeiro

1. The Optimization Landscape

Training a Neural Network implies traversing a high-dimensional mathematical landscape to find the lowest valley (minimum loss).

$$\theta^* = \arg \min_{\theta} J(\theta)$$
  • $\theta$: The model parameters (weights $W$, biases $b$). In deep learning, this can be billions of dimensions.
  • $J(\theta)$: The Loss Function (or Cost Function). A single scalar value evaluating how "bad" the model is.
  • Goal: Find the optimal set of parameters $\theta^*$ where $J$ is minimized.

Minimizing Loss: Gradient Descent

To find the minimum, we compute the gradient (the slope) of the loss function with respect to the weights, and take a small step in the opposite direction.

$$\theta_{new} = \theta_{old} - \alpha \nabla_{\theta} J(\theta)$$

The Gradient ($\nabla$)

A vector containing all partial derivatives (Calculus Chain Rule). Geometrically, it always points in the direction of the steepest ascent. That's why we subtract it (we want to descend the mountain).

Learning Rate ($\alpha$)

A scalar hyperparameter that controls the size of the step we take in the direction of the negative gradient. Choosing this value is the most critical part of training.

The Learning Rate ($\alpha$) Intuition

The learning rate determines how aggressively we update the weights. Getting it wrong ruins training.

Too Small ($\alpha = 10^{-6}$)

Slow convergence. Might get stuck in local minima.

Just Right ($\alpha = 10^{-3}$)

Fast and stable descent to the global/local minimum.

Too Large ($\alpha = 10^{-1}$)

Overshoots the valley. Loss explodes to infinity.

Stochastic Gradient Descent (SGD)

Calculating the true gradient $J(\theta)$ requires running the entire dataset (millions of images) through the network for a single step. This is computationally impossible (out of memory).

The Solution: Minibatches

We approximate the gradient using a small random subset of data (e.g., batch_size = 32). This makes the descent "noisy" (stochastic), but allows for rapid, continuous weight updates.

  • Epoch: One full pass through the entire dataset.
  • Iteration/Step: One forward/backward pass of a single minibatch.

Bonus: The "noise" of minibatches actually helps the network bounce out of shallow local minima!

2. Loss vs. Metric

It is crucial to distinguish these two concepts when designing a machine learning pipeline.

Properties Loss Function ($J$) Evaluation Metric
Purpose Guiding the optimizer (Gradient Descent) during training. Human interpretation & Business rules evaluation.
Requirement Must be Differentiable (smooth) to compute gradients. Can be discrete or non-differentiable (e.g., counting correct answers).
Examples Cross-Entropy, MSE, MAE, Hinge Loss. Accuracy, Precision, Recall, F1, AUC-ROC.

3. Regression Loss: MSE & MAE

Used when the network outputs continuous real values (e.g., Temperature, Bounding Box Coordinates).

Mean Absolute Error (L1)

$$\frac{1}{N} \sum |y - \hat{y}|$$
  • Linear penalty.
  • Robust to outliers (anomalies don't ruin training).

Mean Squared Error (L2)

$$\frac{1}{N} \sum (y - \hat{y})^2$$
  • Quadratic penalty (missing by 10 costs 100).
  • Highly sensitive to outliers. Mathematically smooth.

4. From Logits to Probabilities

Before computing classification loss, we must understand the raw output of a Neural Network.

The final linear layer of a network outputs raw, unbounded real numbers known as Logits (e.g., [2.5, -1.2, 5.0]). These cannot be interpreted as probabilities yet.

The Softmax Function

We apply Softmax to "squash" the logits into a valid probability distribution (values between 0 and 1, summing to 1).

$$\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^K e^{z_j}}$$

Exponentials amplify the largest logit, making the network "confident" in a single class.

Classification Loss: Cross-Entropy

Cross-Entropy measures the distance between the predicted probabilities and the true one-hot labels.

$$\text{CE} = - \sum_{i} y_i \log(p_i)$$

Since $y$ is 1 for the correct class and 0 for others, it simplifies to: $-\log(p_{correct})$.

PyTorch Implementation

# nn.CrossEntropyLoss automatically 
# applies Softmax internally!
# ALWAYS pass raw logits to it.

criterion = nn.CrossEntropyLoss()
loss = criterion(logits, targets)

Log Loss Curve for the Correct Class

If the model is 100% confident and correct ($p=1$), Loss = 0. If it is 100% confident but wrong ($p \to 0$), Loss explodes to $\infty$.

5. Reading the Loss: Overfitting

A training loss of 0.000 is usually bad news. We must track loss on unseen Validation data.

Learning Curves

  • Training Loss: Always goes down. The model is memorizing the training set.
  • Validation Loss: Drops initially, but eventually goes up.

The Overfitting Point

When Validation Loss starts climbing, the model is learning the "noise" of the training data instead of general patterns. We must stop training here.

6. Metrics: The Accuracy Trap

Accuracy is the fraction of correct predictions. It can be highly misleading on imbalanced datasets.

Scenario: Cancer Detection

  • Healthy: 990 patients
  • Cancer: 10 patients

Dummy Model: Hardcodes "Healthy" for absolutely everyone without looking at the data.

  • Accuracy: 99% (Looks amazing on paper!)
  • Utility: 0% (All cancer cases are missed)

This is why we need richer metrics based on the Confusion Matrix:

Predicted Positive Predicted Negative
Actual Positive True Positive (TP) False Negative (FN)
Actual Negative False Positive (FP) True Negative (TN)

Precision, Recall & F1-Score

Precision

"Of all the instances predicted as positive, how many were actually positive?"

$$P = \frac{TP}{TP + FP}$$

Crucial when False Positives are expensive (e.g., Spam Filter blocking important work emails).

Recall (Sensitivity)

"Of all the actual positive instances, how many did the model find?"

$$R = \frac{TP}{TP + FN}$$

Crucial when False Negatives are dangerous (e.g., Missing a Cancer Diagnosis).

The F1-Score

The Harmonic Mean of Precision and Recall. It severely punishes extreme values, providing a single balanced metric.

$$F1 = 2 \cdot \frac{P \cdot R}{P + R}$$

The Decision Threshold & ROC AUC

A classification model outputs a probability (e.g., 0.82). To make a final decision (Yes/No), we must choose a Threshold (usually 0.50).

  • Lower threshold (e.g., 0.20): We flag more positives. Recall increases, but Precision drops (more false alarms).
  • Higher threshold (e.g., 0.90): We are very conservative. Precision increases, but Recall drops (we miss cases).

Area Under Curve (AUC)

Evaluates the model's ability to rank across all possible thresholds.
AUC=1.0 is perfect, AUC=0.5 is useless (random).

Summary

  • Gradient Descent: Updates parameters opposite to the gradient to minimize loss. The Learning Rate dictates the step size.
  • Minibatches (SGD): Allows scaling to massive datasets and helps escape local minima.
  • Loss Functions: MSE is sensitive to outliers (L2), MAE is robust (L1). Cross-Entropy pairs with Softmax for probabilities.
  • Validation Loss: The true indicator of generalization (Overfitting vs Underfitting).
  • Metrics: Accuracy is dangerous on imbalanced data. Use F1-Score or ROC-AUC.
