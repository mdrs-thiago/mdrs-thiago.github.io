1. Evolution of Tasks

Classification

"Cat"

Detection

"Cat" at $(x, y, w, h)$

Multiple labels + Locations.

2. The Bounding Box

We need to predict 4 numbers for each object.

Coordinates

Usually defined as:

  • $x_{center}, y_{center}$: Center of the box.
  • $w, h$: Width and Height.

Plus a class label $c$ and a confidence score $p_c$.

Output Vector:

$[p_c, x, y, w, h, c_1, c_2, ... c_n]$

3. Intersection over Union (IoU)

How do we measure if a prediction is "correct"?

$$ IoU = \frac{\text{Area of Intersection}}{\text{Area of Union}} $$

  • IoU > 0.5: Usually considered a valid detection.
  • IoU = 1.0: Perfect match.

4. The YOLO Architecture

The Backbone: Darknet

YOLO uses a custom CNN called Darknet.

  • Similar to VGG (uses 3x3 convs).
  • Uses Leaky ReLU universally.
  • No MaxPool layers! It uses Stride 2 convolutions to downsample.

The Detection Head

The final output is NOT a vector, but a 3D Tensor.

Conv 1x1 Layer transforms the features into:

$S \times S \times B \cdot (5 + C)$

It effectively predicts a regression vector for every single grid cell simultaneously.

4.1 Understanding the Output

The Grid Concept

Imagine a $7 \times 7$ grid over the image.

Rule: If the center of the Dog is in cell $(3,4)$, ONLY cell $(3,4)$ is responsible for detecting it.

The Vector per Cell

Each cell outputs a vector of size 30:
$[ \underbrace{p, x, y, w, h}_{\text{Box 1}}, \underbrace{p, x, y, w, h}_{\text{Box 2}}, \underbrace{c_1, c_2 ... c_{20}}_{\text{Classes}} ]$

It's a regression problem! The network "spits out" coordinates.

4.2 Why so many boxes?

The "Anchor" Intuition

The network doesn't guess dimensions from scratch. It starts with templates.

  • Anchor 1: Tall (Human)
  • Anchor 2: Wide (Car)
  • Anchor 3: Square (Box)

Total Candidates

$7 \times 7$ Grid cells
$\times 2$ Anchors per cell
$= 98$ Boxes predicted every single time.

Most are garbage (Confidence $\approx$ 0).
We filter them out!

5. Training YOLO

The Loss Function is a "Multi-Part" beast.

$$ \mathcal{L}_{total} = \lambda_{coord} \sum (x,y,w,h \text{ errors}) + \sum (\text{Objectness error}) + \lambda_{noobj} \sum (\text{No Object error}) + \sum (\text{Class error}) $$
1. Localization Loss:
Mean Squared Error (MSE) on coordinates $(x,y, \sqrt{w}, \sqrt{h})$.
Only penalizes the "best" box responsible for the object.
2. Confidence Loss:
- If object exists: Train $p_c \to 1$.
- If background: Train $p_c \to 0$ (Hard Mining!).

6. Cleaning Predictions

YOLO predicts many boxes per object. We need to filter them.

Step 1: Thresholding

Discard boxes with low confidence score (e.g., $< 0.5$).

Step 2: NMS

Non-Max Suppression:

  1. Select box with highest score.
  2. Remove all other boxes with high IoU (overlap) with it.
  3. Repeat.
