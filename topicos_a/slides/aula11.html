Standing on the Shoulders of Giants (like ResNet)

1. The Data Problem

Deep Learning Reality

  • Deep Networks have millions of parameters.
  • To train them from scratch, you need millions of labeled images.
  • Small datasets $\to$ Overfitting.
Question "I only have 1,000 images of medical X-rays. Can I still use Deep Learning?"
YES!

2. ImageNet

The "Encyclopedia" of Computer Vision.

  • 1.2 Million training images.
  • 1,000 object classes (dogs, cats, cars, fruits...).
  • State-of-the-art models (ResNet, VGG, Inception) have been trained on this data for weeks on GPUs.
Idea: These models have already learned how to "see" (detect edges, textures, shapes). We can reuse that knowledge!

3. Feature Extraction

The Logic

  1. Take a pre-trained network (e.g., ResNet18).
  2. Freeze the Convolutional Base (weights won't change).
  3. Replace the final Fully Connected Layer (Classifier).
  4. Train only the new classifier on your small dataset.

When to use?

  • Small dataset.
  • Similar domain to ImageNet (e.g., natural images).

Code: Feature Extraction


import torch
from torchvision import models
import torch.nn as nn

# 1. Load Pre-trained Model
model = models.resnet18(pretrained=True)

# 2. Freeze Parameters
for param in model.parameters():
    param.requires_grad = False

# 3. Replace the Head
# ResNet18's last layer is called 'fc' and has 512 input features.
# We want 2 output classes (e.g., Cat vs Dog).
num_ftrs = model.fc.in_features
model.fc = nn.Linear(num_ftrs, 2)

# Now, only model.fc parameters have requires_grad=True by default!

4. Fine Tuning

The Logic

  1. Initialize with pre-trained weights.
  2. Unfreeze all (or most) layers.
  3. Train the whole network with a very small learning rate.

When to use?

  • Larger dataset.
  • Domain is different from ImageNet (e.g., medical images, satellite).

5. Famous Architectures

Not all CNNs are created equal. Here are the "Hall of Fame" models.

VGG (2014)

Philosophy: "Keep it Simple"

  • Uses only $3 \times 3$ convolutions.
  • Increases depth simply by stacking more layers (16 or 19).
  • Pros: Very easy to understand and implement.
  • Cons: Extremely heavy (138 Million parameters!). Slow to train.

ResNet (2015)

Philosophy: "Let it Flow"

  • Problem: In very deep networks, gradients vanish (become zero) during backprop.
  • Solution: Residual Connections (Skip Connections).
  • $y = F(x) + x$
  • Allows training of 100+ layers (ResNet-50, ResNet-101).

MobileNet & EfficientNet

Modern architectures focus on Efficiency.

MobileNet

  • Uses "Depthwise Separable Convolutions".
  • Splits calculation into spatial vs channel.
  • Great for phones/edge devices.

EfficientNet

  • Uses Compound Scaling.
  • Optimizes Depth, Width, and Resolution simultaneously.
  • Currently the standard for high performance vs. cost.

6. Summary Strategy

Scenario Dataset Size Data Similarity Strategy
1 Small High Feature Extraction (Freeze base, train head)
2 Large High Fine Tuning (Train all, prevent overfitting)
3 Small Low (Medical) Trouble. Try Feature Extraction layers.
4 Large Low Train from Scratch (or Fine Tune)
