Batch, Layer, Instance & Group Norm

1. Batch Normalization

Problem: Internal Covariate Shift.

Solution: Normalize feature mean/var across the Batch usage (N).

$$\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}; \quad y = \gamma \hat{x} + \beta$$

Pros: Allows higher LR, faster convergence.
Cons: Depends on Batch Size. Fails with small batches ($\text{BS} < 8$). Fails in RNNs.

2. Beyond Batch Norm

What if we can't rely on the batch dimension?

Layer Norm (LN)

Normalize across the Channel (C) dimension for a single sample.

Used in Transformers & RNNs. Independent of Batch Size.

Instance Norm (IN)

Normalize each channel independently for each sample.

Used in Style Transfer / GANs to remove contrast info.

Group Normalization (GN)

Middle ground. Divide channels into $G$ groups and normalize within each group.

The "Gold Standard" for Computer Vision with small batches (e.g. Object Detection).

Method Axis of Normalization Best For
Batch (N, H, W) Standard CNNs (Large Batch)
Layer (C, H, W) NLP, Transformers
Instance (H, W) Artistic Style Transfer
Group (Groups of C, H, W) Detection, Segmentation

Q1: The XOR Problem

Why fits a Linear Perceptron fail on XOR?

Because the Activation function is linear.
Because the classes are not linearly separable.
Because it has too many parameters.
Reasoning: XOR points $(0,0), (1,1)$ vs $(0,1), (1,0)$ cannot be separated by a single straight line. You need at least one hidden layer to distort the space.

Q2: Vanishing Gradients

Which activation function helps mitigate Vanishing Gradients?

Sigmoid
Tanh
ReLU
Reasoning: Sigmoid and Tanh squash derivatives into $[0, 0.25]$ or $[0, 1]$. ReLU has a derivative of exactly 1 for positive inputs, allowing gradients to flow unchanged.

Q3: Batch Normalization

Why does Batch Norm fail with batch_size = 1?

Variance is 0 (cannot normalize).
It becomes too slow.
It causes overfitting.
Reasoning: If you have 1 sample, $x_i$ is equal to the mean $\mu$. Thus $x - \mu = 0$ regarding of the value. The statistics become meaningless.
