Backpropagation & Optimization

Connecting Error to Parameters

Thiago Medeiros

Universidade do Estado do Rio de Janeiro

1. Why Backpropagation?

In a Neural Network, we have a Loss Function $L(\theta)$ that tells us how bad our model is based on the final prediction.

We need to change the parameters $\theta$ (weights) throughout the entire network to reduce $L$.

The Core Problem

The weights are "hidden" deep inside the network. We easily know the error at the output, but we need to know exactly how to adjust a specific weight at the very input layer to improve that output.

Strict Definition: Backpropagation is an algorithm to efficiently compute the gradient vector $\nabla_\theta L$ using the Chain Rule of calculus. This vector tells us how sensitive the loss is to every single weight in the network.

Computational Graphs

Modern frameworks (PyTorch, TensorFlow) don't calculate complex derivatives by hand. They break everything down into a Computational Graph.

  • Nodes: Mathematical operations (e.g., $+$, $\times$, $\text{ReLU}$).
  • Edges: Tensors (data) flowing between operations.
  • Forward Pass: Computes the outputs from inputs to loss. We cache intermediate values in memory!
  • Backward Pass: Computes gradients starting from the loss backwards to the inputs.

Example: $f(x,y,z) = (x+y) \cdot z$

The Anatomy of a Node

Every node in the computational graph is completely localized. It only needs to know its inputs, its mathematical operation, and the gradient coming from ahead.

The Golden Rule: $\text{Downstream Gradient} = \text{Upstream Gradient} \times \text{Local Gradient}$

2. A Concrete Example

Let's trace a single Neuron with a Sigmoid activation function. This is the fundamental unit of our network computation.

Forward Pass

  1. Linear combination: $z = w \cdot x + b$
  2. Activation: $a = \sigma(z)$
  3. Loss (MSE): $L = \frac{1}{2}(a - y)^2$

The Goal

We need to calculate $\frac{\partial L}{\partial w}$.

By applying the Chain Rule backwards from output to input:

$$ \frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} \cdot \frac{\partial a}{\partial z} \cdot \frac{\partial z}{\partial w} $$

Computing the Terms

Term Mathematical Derivative Intuitive Meaning
$\frac{\partial L}{\partial a}$ $(a - y)$ The Error Signal.
Direction and magnitude of the mistake. Positive if prediction $a$ is too high, negative if too low.
$\frac{\partial a}{\partial z}$ $\sigma'(z) = a(1-a)$ Local Sensitivity.
How much the neuron's activation changes when its linear input sum changes.
$\frac{\partial z}{\partial w}$ $x$ Input Strength.
Weights connected to strong input signals ($x$) get updated more aggressively.
$$ \frac{\partial L}{\partial w} = (a-y) \cdot a(1-a) \cdot x $$

We found the exact algebraic formula to update $w$ based on the final error!

3. Weight Initialization

Now that we know how weights update ($\Delta w \propto x$), what happens if we initialize all weights in the network to Zero?

The Symmetry Problem

  • If $W = 0$, every neuron in a hidden layer computes the exact same output ($0 \cdot x + b$).
  • During backpropagation, the gradients flowing backwards will be identical for every neuron.
  • Therefore, every weight will receive the exact same update.

Conclusion: If all weights update identically, the neurons will never learn different features (e.g., one finding edges, another finding colors). The network effectively acts as if it has only one neuron per layer.

Solution: We must initialize weights with small Random Numbers to break the symmetry!

4. The Optimization Landscape

Finding the optimal weights is like walking down a mountain range in the dark, feeling the slope with your feet.

A highly non-convex Loss Landscape typically found in Deep Neural Networks.

Challenges in Optimization

Local Minima

Valleys that are not the absolute lowest point in the landscape.

The optimizer gets stuck because the gradient is exactly 0, but the overall loss is still high.

Saddle Points

Points where the slope is 0, but it is a minimum in one dimension and a maximum in another.

Fact: In high-dimensional spaces (millions of parameters), saddle points are drastically more common than local minima.

The Vanishing Gradient Problem

Recall that the Chain Rule implies continuous multiplication across layers: $\nabla L = g_1 \cdot g_2 \cdot g_3 \dots$

The issue with Sigmoid

If we use Sigmoid activation, the maximum possible value for its derivative is exactly $0.25$. When we backpropagate through 3 hidden layers:

$$ 0.25 \times 0.25 \times 0.25 \approx 0.015 $$

In deep networks, gradients become effectively zero for the early layers. The front of the network simply stops learning.

Modern Solutions: Use the ReLU activation function (its derivative is constantly 1 for positive inputs, avoiding shrinkage) and Architectural Skip Connections (like in ResNets).

5. Advanced Optimizers: Momentum

Vanilla Stochastic Gradient Descent (SGD) blindly follows the local slope. This causes major issues in "ravines" (areas where the surface curves much more steeply in one dimension than in another).

The SGD Oscillation Problem

SGD will violently oscillate across the steep slopes of the ravine while making very slow progress towards the local minimum along the flat center.

The Solution: Momentum

Instead of using only the current gradient, we maintain a "moving average" of past gradients (velocity).

  • Dampens oscillations: Opposing gradients cancel each other out over time.
  • Builds speed: Gradients pointing in the same direction add up.
  • Analogy: A heavy snowball rolling down a hill.

SGD vs. Momentum in a Ravine

RMSProp & Adam Optimizer

RMSProp (Root Mean Square Prop.)

What if we adapt the learning rate for each individual parameter in the network?

  • Maintains a moving average of squared gradients.
  • Divides the base learning rate by this average.
  • Result: Flat dimensions automatically get a larger learning rate (speeding up), and steep dimensions get a smaller learning rate (preventing explosion).

Adam (Adaptive Moment Estimation)

The undisputed industry standard. It elegantly combines both strategies to get the best of both worlds:

Adam = Momentum + RMSProp
  • Uses $v$ (velocity) from Momentum to smooth direction.
  • Uses $s$ (squared gradients) from RMSProp to adapt step size.
import torch.optim as optim

# A inicializar o otimizador Adam
# lr = taxa de aprendizagem (learning rate) base
optimizer = optim.Adam(
    model.parameters(), lr=0.001)

Summary

  • Computational Graphs: Frameworks cache forward pass data to efficiently run the backwards pass using the Chain Rule.
  • Weight Initialization: Must be random to break symmetry.
  • The Neuron Update: $\Delta w = \text{Error} \times \text{Derivative} \times \text{Input}$.
  • Obstacles: Saddle Points and Local Minima stall training. Vanishing Gradients kill deep networks.
  • Optimizers: Use Adam (Momentum + RMSProp) to navigate the loss landscape faster and more safely than basic SGD.
