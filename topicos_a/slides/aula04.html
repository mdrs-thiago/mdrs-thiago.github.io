Backpropagation & Optimization Landscapes

Thiago Medeiros

Connecting Error to Parameters

1. Why Backpropagation?

In a Neural Network, we have a Loss Function $L(\theta)$ that tells us how bad our model is.

We need to change the parameters $\theta$ (weights) to reduce $L$.

The Core Problem: The weights are "hidden" deep inside the network. We know the error at the output, but we need to know how to adjust a weight at the input layer.

Strict Definition: Backpropagation is an algorithm to efficiently compute the gradient vector $\nabla_\theta L$. This vector points in the direction of steepest ascent. We interpret it to move in the opposite direction (Descent).

2. A Concrete Example

Let's trace a single Neuron with Sigmoid activation. This is a realistic unit of a network.

Forward Pass

  1. Linear: $z = w \cdot x + b$
  2. Activation: $a = \sigma(z)$
  3. Loss: $L = \frac{1}{2}(y - a)^2$ (MSE)

The Goal

We need $\frac{\partial L}{\partial w}$.

Using Chain Rule:

$$ \frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} \cdot \frac{\partial a}{\partial z} \cdot \frac{\partial z}{\partial w} $$

Computing the Terms

Term Math Intuition
$\frac{\partial L}{\partial a}$ $-(y - a)$ The Error Signal.
If prediction $a$ is too low, gradient is negative (increase $a$).
$\frac{\partial a}{\partial z}$ $\sigma'(z) = a(1-a)$ Local Sensitivity.
How much the activation changes when input sum changes.
$\frac{\partial z}{\partial w}$ $x$ Input Strength.
Weights connected to strong inputs get updated more.
$$ \frac{\partial L}{\partial w} = -(y-a) \cdot a(1-a) \cdot x $$ We found the exact formula to update $w$ based on the final error!

3. The Optimization Landscape

Finding the optimal weights is like walking down a mountain in the dark (Gradient Descent).

A non-convex Loss Landscape.

Challenges in Optimization

Local Minima

Valleys that are not the lowest point.

The optimizer gets stuck because gradient is 0, but loss is still high.

Saddle Points

Points where the slope is 0, but it's a minimum in one dimension and maximum in another.

Fact: In high dimensions, saddle points are much more common than local minima.

The Vanishing Gradient Problem

Recall the Chain Rule implies multiplication: $\nabla L = g_1 \cdot g_2 \cdot g_3 \dots$

If we use Sigmoid, the max derivative is $0.25$.

$$ 0.25 \times 0.25 \times 0.25 \approx 0.015 $$

In deep networks, gradients become effectively zero for the early layers. The front of the network stops learning.

Solution: Use ReLU (derivative is 1 or 0) and Skip Connections (ResNets).

Summary

  • Backprop computes $\nabla L$ by applying Chain Rule from Output $\to$ Input.
  • For a neuron, Update = Error $\times$ Derivative $\times$ Input.
  • Optimization navigates a complex, non-convex landscape.
  • Saddle Points and Local Minima stall training.
  • Vanishing Gradients kill deep networks (solved by modern architectures).
