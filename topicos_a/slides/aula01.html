The Perceptron & MLPs

Understanding the Building Blocks of Deep Learning

1. Biological Inspiration

Deep Learning is loosely inspired by neuroscience. The goal is not to clone the brain, but to abstract its core principles of computation.

The Biological Neuron

  • Dendrites: Receivers. Collect chemical signals from other neurons.
  • Soma (Cell Body): Accumulator. Sums interactions over time.
  • Axon Hillock: Decision center. If the sum exceeds a threshold, fire!
  • Axon: Transmitter. Sends the electrical spike to the next neurons.

Fig 1: Anatomy of a Biological Neuron.

From Biology to Mathematics

We model this biological process as a weighted sum followed by a non-linear activation.

$$ \text{Output} = f\left( \sum_{i=1}^{n} w_i x_i + b \right) $$
  • $x_i$: Input signals (features or previous layer outputs).
  • $w_i$: Synaptic strength (weights). Can be excitatory ($+$) or inhibitory ($-$).
  • $b$: Bias (native excitability threshold of the neuron).
  • $f$: Activation function (determines the firing rate saturation).

2. The Perceptron

Proposed by Frank Rosenblatt (1958). It is the simplest possible Neural Network: a single artificial neuron with a Heaviside (Step) activation function.

The Mathematical Model

For a binary classification problem $y \in \{0, 1\}$:

$$ \hat{y} = \begin{cases} 1 & \text{if } w \cdot x + b > 0 \\ 0 & \text{otherwise} \end{cases} $$

Geometric Interpretation

The equation $w \cdot x + b = 0$ defines a Hyperplane (decision boundary) that slices the input space into two distinct regions.

The Learning Algorithm

How do we find the optimal $w$ and $b$? We use an error-driven update rule.

  1. Initialize weights randomly (e.g., close to zero).
  2. For each training sample $(x^{(i)}, y^{(i)})$:
    • Compute prediction: $\hat{y} = \text{step}(w \cdot x + b)$
    • Update weights using the error:
      $$ w \leftarrow w + \eta (y^{(i)} - \hat{y}) x^{(i)} $$
  3. Repeat until convergence (no errors on the training set).

Intuition: If the prediction is wrong, the rule pushes the weight vector $w$ towards (or away from) the input vector $x$ to correct the boundary.

3. Limitations: The XOR Problem

In 1969, Minsky & Papert published Perceptrons, proving a fatal flaw: single-layer networks cannot solve problems that are not linearly separable.

Logical Gates

AND / OR: Linearly Separable. A single straight line can split the 0s from the 1s.

XOR (Exclusive OR): NON-Linearly Separable. You absolutely need two lines (or a curve) to solve it.

4. Multi-Layer Perceptron (MLP)

The solution is to stack perceptrons using Hidden Layers between the input and output layers, forming a deep network.

import torch.nn as nn

# A Simple MLP in PyTorch to solve XOR
model = nn.Sequential(
    nn.Linear(2, 4),    # Hidden Layer: Learns 4 new features
    nn.ReLU(),          # Non-Linearity (Crucial to break linearity!)
    nn.Linear(4, 1),    # Output Layer: Final decision
    nn.Sigmoid()        # Maps output to a probability (0 to 1)
)

Understanding Hidden Layers

What does a hidden layer actually do to the data geometrically?

Feature Space Transformation

The hidden layer maps the raw inputs into a higher-dimensional (or warped) space. In this new space, the data that was tangled up becomes linearly separable for the final output layer.

Note: To train hidden layers, we can no longer use the simple Perceptron rule. We need Calculus (The Chain Rule) → Backpropagation.

5. Activation Functions

Without non-linear activation functions, stacking layers is useless. A deep linear network collapses into a single linear matrix!

$$ W_2(W_1 x + b_1) + b_2 = (W_2 W_1)x + (W_2 b_1 + b_2) = W'x + b' $$

No matter how many layers you stack, it represents just one line.

Common Activation Functions

Name Function Shape Pros/Cons
Sigmoid $\frac{1}{1+e^{-x}}$ Outputs interpretable probability $(0, 1)$.
Cons: Vanishing Gradient.
Tanh $\tanh(x)$ Zero-centered output $(-1, 1)$.
Cons: Vanishing Gradient.
ReLU $\max(0, x)$ Computationally efficient, prevents saturation.
Cons: Dead neurons issue.

Summary

  • Perceptrons are simple linear classifiers ($w \cdot x + b$).
  • They fail completely on non-linearly separable data (like XOR).
  • MLPs introduce hidden layers to geometrically warp the feature space.
  • Non-linear activations (ReLU, Sigmoid) are strictly required for deep learning to work.
