CNNs in PyTorch

Building Custom Architectures with `torch.nn`

Thiago Medeiros

Universidade do Estado do Rio de Janeiro

1. Image Tensors in PyTorch

In PyTorch, batches of images are strictly represented as 4-Dimensional tensors.

(N, C, H, W)
  • N (Batch Size): Number of images processed simultaneously (e.g., 32).
  • C (Channels): Depth. 3 for RGB, 1 for Grayscale.
  • H (Height): Vertical resolution in pixels.
  • W (Width): Horizontal resolution in pixels.

Instantiating a Dummy Batch

import torch

# Creating a batch of 10 random 
# RGB images, size 32x32 pixels
x = torch.randn(10, 3, 32, 32)

print(x.shape)
# Output: torch.Size([10, 3, 32, 32])

Warning: TensorFlow/Keras uses (N, H, W, C) by default. Be very careful with dimension ordering when porting code between frameworks!

2. The Convolution Layer

The workhorse of Computer Vision is the nn.Conv2d module. It automatically initializes and manages the learnable filter weights.

import torch.nn as nn

layer = nn.Conv2d(
    in_channels=3,   # Input depth (e.g. RGB)
    out_channels=16, # Num of Filters
    kernel_size=3,   # 3x3 Filter
    stride=1,        # Step size
    padding=1        # Zeros around border
)

Note: The actual weight tensor inside this layer will have shape [16, 3, 3, 3] (Out, In, H, W).

Shape Transformation

Applying this layer to an image batch:

  • Input: $(N, \mathbf{3}, 32, 32)$
  • Output: $(N, \mathbf{16}, 32, 32)$

Because padding=1 and kernel=3, the spatial dimensions ($32 \times 32$) remain identical. Only the channels changed (from 3 colors to 16 feature maps).

3. Pooling & Activation

Convolutions are strictly linear operations. We must add a Non-Linearity (ReLU) and usually downsample the spatial resolution (MaxPool) immediately after.

Max Pooling

pool = nn.MaxPool2d(
    kernel_size=2,
    stride=2
)
  • Input: $(N, 16, 32, 32)$
  • Output: $(N, 16, \mathbf{16}, \mathbf{16})$

Depth remains 16. Spatial size drops by exactly half, significantly reducing VRAM usage.

ReLU Activation

Any negative values (e.g., a filter found the exact opposite of its pattern) are zeroed out.

import torch.nn.functional as F

# Applied functionally
x = F.relu(x)

ReLU does not change tensor shapes, only the internal values.

4. The Flattening Math

CNNs extract 2D spatial features, but the final classification decision requires a 1D vector to feed into a Standard Linear Layer (MLP).

3D Tensor to 1D Vector

Calculating the Size

If the final feature map before the classification head has shape $(N, 32, 8, 8)$, we must multiply the spatial and depth dimensions:

$$ 32 \times 8 \times 8 = 2048 $$

The Linear layer that follows must have in_features=2048.

5. Architecture: The __init__

We build models in PyTorch by inheriting from nn.Module. In the constructor, we register all layers that contain learnable parameters (Weights/Biases).

class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__() # CRITICAL: Initializes the PyTorch backend
        
        # Feature Extractor Block 1
        self.conv1 = nn.Conv2d(3, 16, kernel_size=3, padding=1)
        self.pool = nn.MaxPool2d(kernel_size=2, stride=2)
        
        # Feature Extractor Block 2
        self.conv2 = nn.Conv2d(16, 32, kernel_size=3, padding=1)
        
        # Classification Head
        # The 2048 comes from our flattening math!
        self.fc1 = nn.Linear(in_features=32 * 8 * 8, out_features=100) 
        self.fc2 = nn.Linear(in_features=100, out_features=10) # 10 Classes

Architecture: The forward Pass

The forward method dictates exactly how data (the image tensor x) flows through the registered layers. Operations without weights (like ReLU) are applied here.

    def forward(self, x):
        # Block 1: Conv -> ReLU -> Pool
        # Shape: (N, 3, 32, 32) -> (N, 16, 16, 16)
        x = self.pool(F.relu(self.conv1(x)))
        
        # Block 2: Conv -> ReLU -> Pool (reusing the same pool layer)
        # Shape: (N, 16, 16, 16) -> (N, 32, 8, 8)
        x = self.pool(F.relu(self.conv2(x)))
        
        # FLATTEN: The -1 tells PyTorch to preserve the Batch size (N)
        # Shape: (N, 32, 8, 8) -> (N, 2048)
        x = x.view(-1, 32 * 8 * 8) 
        
        # Classifier
        x = F.relu(self.fc1(x))
        x = self.fc2(x) # Raw Logits output
        
        return x

6. The "Flattening" Trap

The most common error encountered by beginners writing CNNs from scratch:

RuntimeError: mat1 and mat2 shapes cannot be multiplied (32x2048 and 500x10)

The Cause

You miscalculated the spatial shrinking. The input size of your first Linear layer (e.g., 500) does not match the actual flattened output size of your final Conv/Pool layer (e.g., 2048).

The Engineer's Solution

Before writing the Linear layers, pass a "dummy tensor" through the conv layers to literally print its shape:

dummy = torch.randn(1, 3, 32, 32)
out = self.pool(F.relu(self.conv2(
      self.pool(F.relu(self.conv1(dummy))))))
print(out.shape) # Result gives you the math!

7. The Training Loop

The standard PyTorch loop ("The Big 5") remains identical! We just feed image batches instead of tabular vectors.

model = SimpleCNN().to(device)
criterion = nn.CrossEntropyLoss() # Applies Softmax automatically
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

model.train() # Set to training mode (enables Dropout/BatchNorm)

for epoch in range(num_epochs):
    for images, labels in train_loader:
        images, labels = images.to(device), labels.to(device)
        
        # 1. Forward Pass
        logits = model(images)
        loss = criterion(logits, labels)
        
        # 2. Backward Pass & Optimize
        optimizer.zero_grad() # Clear old gradients
        loss.backward()       # Compute new gradients
        optimizer.step()      # Update weights

8. Evaluation & Inference

When making predictions on new data, we must turn off gradient tracking and switch the model's behavior mode.

model.eval() # CRITICAL: Freezes BatchNorm and disables Dropout

correct = 0
total = 0

# Disables Autograd engine (saves memory and speeds up computation)
with torch.no_grad():
    for images, labels in test_loader:
        images, labels = images.to(device), labels.to(device)
        
        logits = model(images)
        
        # logits shape: (Batch_Size, 10_Classes)
        # argmax(dim=1) gets the index of the highest probability
        _, predicted_class = torch.max(logits, dim=1) 
        
        total += labels.size(0)
        correct += (predicted_class == labels).sum().item()

print(f"Test Accuracy: {100 * correct / total:.2f}%")

Summary & Next Steps

  • Image Tensors: Always use the format (Batch, Channels, Height, Width) in PyTorch.
  • Conv & Pool: Use nn.Conv2d for feature extraction and nn.MaxPool2d for spatial downsampling.
  • Flattening: You must manually reshape the 3D feature map into a 1D vector (e.g., x.view(-1, features)) before the nn.Linear classifier head.
  • State Modes: Always remember to toggle between model.train() and model.eval().
