Building Custom Architectures with `torch.nn`

1. Image Tensors

Dimensions

In PyTorch, images are represented as 4D tensors:

(N, C, H, W)
  • N: Batch Size (e.g., 32 images)
  • C: Channels (3 for RGB, 1 for Grayscale)
  • H: Height (pixels)
  • W: Width (pixels)

Example


import torch

# A batch of 10 RGB images, 32x32 size
x = torch.randn(10, 3, 32, 32)

print(x.shape)
# torch.Size([10, 3, 32, 32])

Note: TensorFlow uses (N, H, W, C). Be careful when porting code!

2. The Convolution Layer

nn.Conv2d

The workhorse of CNNs.


nn.Conv2d(
    in_channels=3,   # Input depth (e.g. RGB)
    out_channels=16, # Number of Filters (Kernels)
    kernel_size=3,   # 3x3 Filter
    stride=1,
    padding=1
)

What happens?

  • Input: $(N, 3, H, W)$
  • Output: $(N, 16, H, W)$

We started with 3 "color planes" and ended up with 16 "feature maps" (e.g., edges, textures).

3. Pooling

Downsampling the feature maps.


nn.MaxPool2d(
    kernel_size=2,
    stride=2
)

This layer reduces Height and Width by half.

  • Input: $(N, 16, 32, 32)$
  • Output: $(N, 16, 16, 16)$

Depth (Channels) remains 16. Spatial size drops.

4. Building a Simple CNN


import torch.nn as nn
import torch.nn.functional as F

class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()
        # Layer 1: Conv -> Pool
        # Input: (3, 32, 32) -> Output Conv: (16, 32, 32) (padding=1)
        # Pool: (16, 16, 16)
        self.conv1 = nn.Conv2d(3, 16, kernel_size=3, padding=1)
        self.pool = nn.MaxPool2d(2, 2)
        
        # Layer 2: Conv -> Pool
        # Input: (16, 16, 16) -> Output Conv: (32, 16, 16)
        # Pool: (32, 8, 8)
        self.conv2 = nn.Conv2d(16, 32, kernel_size=3, padding=1)
        
        # Fully Connected Layer
        # Input features must match the flattened size: 32 * 8 * 8 = 2048
        self.fc1 = nn.Linear(32 * 8 * 8, 100) # Hidden layer
        self.fc2 = nn.Linear(100, 10)         # Output layer (10 classes)

    def forward(self, x):
        x = self.pool(F.relu(self.conv1(x)))
        x = self.pool(F.relu(self.conv2(x)))
        
        # FLATTEN: (N, 32, 8, 8) -> (N, 2048)
        x = x.view(-1, 32 * 8 * 8) 
        
        x = F.relu(self.fc1(x))
        x = self.fc2(x)
        return x

5. The "Flattening" Trap

The most common error in beginner CNN code:

RuntimeError: mat1 and mat2 shapes cannot be multiplied (32x2048 and 500x10)

Cause

The input size of your first Linear layer (`self.fc1`) does not match the output size of your last Convolution/Pool layer.

Solution

  1. Trace your dimensions manually (Input W $\to$ Conv $\to$ Pool...).
  2. Use a "dummy input" to print the shape inside `__init__`.

6. Training Loop

Standard PyTorch loop, just feeding image batches.


model = SimpleCNN()
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

for images, labels in train_loader:
    # 1. Forward
    outputs = model(images)
    loss = criterion(outputs, labels)
    
    # 2. Backward
    optimizer.zero_grad()
    loss.backward()
    
    # 3. Update
    optimizer.step()

Note: `nn.CrossEntropyLoss` already includes Softmax!
