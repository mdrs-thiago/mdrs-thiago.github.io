Regularization

Bias, Variance, and Model Constraints

Thiago Medeiros

Universidade do Estado do Rio de Janeiro

1. The Bias-Variance Tradeoff

The total error of a model on unseen test data can be mathematically decomposed into three components:

$$ \text{Total Error} = \text{Bias}^2 + \text{Variance} + \text{Irreducible Noise} $$

Bias (Systematic Error)

The error introduced by approximating a highly complex real-world problem with a simplified model (e.g., using a straight line for non-linear data).

High Bias $\rightarrow$ Underfitting. The model ignores the training data and fails to capture underlying patterns.

Variance (Sensitivity)

The amount by which the model's predictions would wildly change if we trained it on a slightly different dataset.

High Variance $\rightarrow$ Overfitting. The model pays too much attention to the training data, capturing random noise as truth.

Visualizing the Tradeoff

As model complexity (number of parameters/layers) increases, Bias decreases but Variance increases.

2. Regularization as a Constraint

How do we forcefully reduce Variance (limit complexity) without destroying the model's capacity to learn?

The Lagrange Multiplier Perspective

We add a penalty term ($\Omega$) to the loss function. We tell the network: "Fit the data well, BUT keep the weights as small and simple as possible."

$$ J_{reg}(\theta) = J_{data}(\theta) + \lambda \Omega(\theta) $$
  • $J_{data}(\theta)$: Standard loss (MSE, Cross-Entropy). Encourages fitting the data.
  • $\Omega(\theta)$: The penalty on the weights. Encourages simplicity.
  • $\lambda$: The Regularization Strength. Hyperparameter controlling the trade-off.

3. Types of Penalties: L1 vs L2

Norm Formula ($\Omega$) Effect on Weights
L2 (Ridge) $\sum w_i^2$ Weight Decay. Shrinks weights linearly towards zero. Diffuses credit smoothly across many neurons.
L1 (Lasso) $\sum |w_i|$ Sparsity. Forces many weights to be exactly zero. Acts as an aggressive feature selector.

Standard in DL: L2 is overwhelmingly preferred in Deep Learning because it's smoothly differentiable everywhere.

Geometric View (Lagrange Constraint)

L1 hits corners (Sparse = exactly 0 in one axis).
L2 hits tangentially (Small weights, but non-zero).

The Math of L2 (Weight Decay)

If we apply the gradient descent update rule to $J_{reg} = J_{data} + \frac{\lambda}{2}w^2$:

$$ \nabla_w J_{reg} = \nabla_w J_{data} + \lambda w $$ $$ w_{new} = w_{old} - \eta (\nabla_w J_{data} + \lambda w_{old}) $$ $$ w_{new} = (1 - \eta \lambda) w_{old} - \eta \nabla_w J_{data} $$

The term $(1 - \eta\lambda)$ is slightly less than 1. This means at every single step, we artificially shrink the weight by a tiny fraction before applying the data gradient. Hence the name Weight Decay.

Implementation in PyTorch

import torch.optim as optim

# O Weight Decay é construído 
# diretamente nos optimizers!
optimizer = optim.Adam(
    model.parameters(), 
    lr=1e-3, 
    weight_decay=1e-4 # Penalidade L2
)

4. Early Stopping as Regularization

A simpler, highly effective method: simply halt the training process before the model has a chance to memorize the noise.

The Implicit Constraint

Weights are initialized near zero. By limiting the number of optimization steps (epochs), we implicitly restrict how far the weights can travel from the origin.

Mathematically, Early Stopping acts exactly like an L2 constraint, without needing to tune a $\lambda$ parameter!

5. Data Augmentation

The ultimate cure for High Variance is more training data. When we don't have more data, we artificially synthesize it.

By applying random transformations (rotations, flips, color jitter, crops), the network never sees the exact same input twice. This forces the model to learn invariant features (e.g., a dog is a dog, even upside down).

from torchvision import transforms

# Pipeline de transformações
train_transforms = transforms.Compose([
    transforms.RandomHorizontalFlip(),
    transforms.RandomRotation(15),
    transforms.ColorJitter(brightness=0.2),
    transforms.ToTensor()
])

6. Dropout Regularization

A technique specific to Deep Learning (Hinton et al., 2012): Randomly disabling a fraction $p$ of neurons during each forward pass.

Why does destroying data help?

  • Prevents Co-adaptation: Neurons can't rely on specific other neurons to fix their mistakes. Every neuron must learn independently useful features.
  • Ensemble Effect: Dropping nodes trains $2^N$ different "thinner" sub-networks. At test time, using all nodes acts like averaging a massive ensemble of models.

Implementation

import torch.nn as nn

model = nn.Sequential(
    nn.Linear(256, 128),
    nn.ReLU(),
    # 50% de probabilidade de zerar
    # ATIVO APENAS durante o treino
    nn.Dropout(p=0.5), 
    nn.Linear(128, 10)
)

The Secret: Inverted Dropout

How PyTorch actually implements Dropout under the hood.

The Problem: If we drop 50% of the neurons during training, the expected sum of activations is halved. During Testing/Inference, we want to use 100% of the neurons. This creates a massive scaling mismatch!

Original Dropout

Multiply by $(1-p)$ at Test time to reduce the signal.

Annoying, because inference code must change based on training hyperparameters.

Inverted Dropout (PyTorch)

Divide the active neurons by $(1-p)$ during Training to artificially boost their signal.

Elegant, because Test time requires literally zero changes! The `model.eval()` just turns Dropout into an identity function.

7. Batch Normalization

Designed primarily to stabilize gradients and speed up training, it brings a massive side effect: Implicit Regularization.

$$\hat{x}_i = \frac{x_i - \mu_{\mathcal{B}}}{\sqrt{\sigma_{\mathcal{B}}^2 + \epsilon}}$$

Because $\mu$ and $\sigma$ are calculated on a random mini-batch $\mathcal{B}$, every training example is slightly "jittered" by the other examples in the same batch.

The Effect

This noise discourages the network from relying on highly specific deterministic values. In modern architectures (like ResNets), Batch Normalization is so effective that Dropout is often completely removed.

Summary

  • Bias vs Variance: High Bias = Underfitting. High Variance = Overfitting.
  • Regularization: Constrains model capacity to improve generalization.
  • L2 (Weight Decay): Shrinks weights mathematically. L1 forces sparsity.
  • Early Stopping: Halts training before the model memorizes noise.
  • Data Augmentation: Synthesizes new data to enforce invariant features.
  • Dropout: Prevents co-adaptation via random node dropping (Inverted in PyTorch).
  • Batch Norm: Adds statistical noise per batch, acting as implicit regularization.
