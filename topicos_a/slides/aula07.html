Bias, Variance, and Model Constraints

1. Expected Error Decomposition

The total error of a model on unseen data can be broken down:

$$ E = \text{Bias}^2 + \text{Variance} + \text{Noise} $$

Defining the Terms Rigorously

Bias (Systematic Error)

The error introduced by approximating a real-world problem (which may be extremely complex) by a simplified model.

High Bias: The model pays very little attention to the training data and oversimplifies the model. It fails to capture the underlying patterns.

Variance (Sensitivity)

The amount by which the estimate of the target function would change if we used a different training data set.

High Variance: The model pays too much attention to the training data, capturing random noise as if it were signal.

2. Regularization as a Constraint

How do we reduce Variance without exploding Bias?

Lagrange Multipliers: $$ \text{Minimize } J(w) + \lambda \|w\| $$

We penalize complexity. We say: "Fit the data well, BUT keep the weights small/simple."

3. L1 vs L2 Norms

Norm Formula ($\Omega$) Effect
L2 (Ridge) $\sum w_i^2$ Weight Decay. Shrinks weights linearly. Diffuses credit across many neurons. Preferred for Deep Learning.
L1 (Lasso) $\sum |w_i|$ Sparsity. Forces weights to exactly zero. Acts as strict feature selection.

4. Dropout

Randomly disabling neurons during training to force redundancy.

Ensemble Effect

By dropping units, we prevent neurons from co-adapting too much. Each neuron must be independently useful.

Effectively, we are training $2^N$ sub-networks. At test time, using the full network is equivalent to averaging their predictions.

Summary

  • Bias is simplification error; Variance is sensitivity error.
  • Regularization aims to find the sweet spot in this trade-off.
  • L2 (Weight Decay) is the standard "smoothing" prior.
  • Dropout creates robust, redundant representations.
