The Training Loop

Thiago Medeiros

Putting it all together: Data, Model, Loss, Optimizer.

1. Anatomy of Training

Every Deep Learning script follows the same skeleton.

1. Setup Hyperparameters
2. Load Data (DataLoader)
3. Initialize Model, Loss, Optimizer
4. Loop over Epochs:
   4.1. Loop over Batches:
     a. Forward Pass (Predict)
     b. Compute Loss (Evaluate)
     c. Backward Pass (Gradient)
     d. Optimizer Step (Update)
     e. Zero Gradients (Reset)

The "Big 5" Code

Memorize these 5 lines. They are the heartbeat of PyTorch.


# Inside the batch loop:

# 1. Forward
y_pred = model(X_batch)

# 2. Loss
loss = criterion(y_pred, y_batch)

# 3. Backward
loss.backward()

# 4. Step
optimizer.step()

# 5. Reset
optimizer.zero_grad()

Common Pitfall: Forgetting zero_grad() causes gradients to accumulate (sum up) instead of replacing.

2. Epochs vs Batches

We rarely train on the whole dataset at once (GD). We use Mini-Batch SGD.

  • Epoch: One complete pass through the entire dataset.
  • Batch Size: Number of samples processed before updating weights.
  • Iteration: One update step.
Example:
1000 Images.
Batch Size = 100.

$\rightarrow$ 10 Iterations per Epoch.

Underfitting vs Overfitting

The fundamental trade-off in Machine Learning.

State Symptom Cause Solution
Underfitting High Training Loss.
High Validation Loss.		 Model too simple (low capacity). More layers/neurons.
Train longer.
Overfitting Low Training Loss.
Rising Validation Loss.		 Model memorizing noise. Regularization (Dropout).
More Data.

Visualizing Generalization

We stop training when Validation Loss starts increasing (Early Stopping).

3. Choosing Hyperparameters

Deep Learning is often called "Alchemy" because of these magic numbers.

  • Learning Rate ($\eta$): The most important one.
    • Too high: Diverges (Loss explodes).
    • Too low: Slow convergence.
    • Rule of Thumb: Start at $3e-4$ (Andrej Karpathy's Constant).
  • Batch Size: Usually 32, 64, or 128. Powers of 2 fit GPU memory better.
  • Optimizer:
    • SGD: Solid, predictable, needs tuning.
    • Adam: Adaptive, generally "just works".

Saving & Loading

Don't lose your work.


 # Save weights only (Recommended)
 torch.save(model.state_dict(), "model.pth")

 # Load
 model = MyModel()
 model.load_state_dict(torch.load("model.pth"))
 model.eval() # Set to inference mode
