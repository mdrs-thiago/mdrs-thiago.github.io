SYSTEM = """Você responde perguntas sobre o documento
fornecido. Use APENAS os trechos abaixo. Cite a página
entre colchetes, ex.: [p. 12]. Se a resposta não
estiver nos trechos, diga "Não encontrei no documento"."""

def answer(q, k=4):
    hits = retrieve(q, k)
    ctx = "\n\n".join(
        f"[p. {h['page']}] {h['text']}" for h in hits)
    msgs = [
        {"role": "system", "content": SYSTEM},
        {"role": "user", "content":
            f"<trechos>\n{ctx}\n</trechos>\n\nPergunta: {q}"},
    ]
    return generate(msgs, temperature=0.1), hits
  • Temperatura baixa: queremos fidelidade, não criatividade (Aula 22)
  • Permitir "não encontrei" reduz alucinação
  • Delimitadores separam dados de instruções
  • Guarde os hits para avaliar o retrieval separadamente
