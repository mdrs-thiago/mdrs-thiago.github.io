  • Projetar um pipeline de augmentation que respeite o domínio
  • Camadas iniciais aprendem bordas, cores, texturas: úteis para quase qualquer imagem
  • Camadas finais aprendem conceitos específicos do dataset original (focinho de cachorro, roda de carro)
  • Yosinski et al. (2014): transferir as primeiras camadas quase sempre ajuda; as últimas, só se as tarefas forem parecidas

Uma ResNet pré-treinada no ImageNet viu 1,2 M imagens. Seu dataset de 500 fotos "herda" esse conhecimento.

❄️ Feature extraction

Congela todo o backbone; treina só a nova cabeça.

Quando: poucos dados, domínio parecido.

Custo: mínimo.

🌗 Fine-tuning parcial

Congela as primeiras camadas; treina as últimas + cabeça.

Quando: dados médios ou domínio um pouco diferente.

🔥 Fine-tuning completo

Treina tudo, partindo dos pesos pré-treinados, com LR pequeno.

Quando: muitos dados ou domínio bem diferente.

Domínio parecidoDomínio diferente
Poucos dadosFeature extractionFine-tuning parcial (camadas iniciais) + muita augmentation
Muitos dadosFine-tuning completoFine-tuning completo (ou até do zero)
from torchvision import models

w = models.ResNet18_Weights.IMAGENET1K_V1
model = models.resnet18(weights=w)
preprocess = w.transforms()   # resize, crop, normalize

# 1) Feature extraction: congela tudo
for p in model.parameters():
    p.requires_grad = False

# 2) Nova cabeça (treinável por padrão)
model.fc = nn.Linear(model.fc.in_features, n_classes)

opt = torch.optim.AdamW(
    [p for p in model.parameters() if p.requires_grad],
    lr=1e-3)
# Fine-tuning completo com LRs discriminativos
for p in model.parameters():
    p.requires_grad = True

opt = torch.optim.AdamW([
    {'params': model.layer4.parameters(), 'lr': 1e-4},
    {'params': model.fc.parameters(),     'lr': 1e-3},
    # demais camadas: LR ainda menor
], weight_decay=1e-2)

Use a mesma normalização do pré-treino (médias/desvios do ImageNet). Ao congelar um backbone com BatchNorm, mantenha essas camadas em eval() para não alterar as estatísticas.

Aplicar transformações aleatórias a cada época: a rede nunca vê exatamente a mesma imagem duas vezes.

  • Geométricas: flip, rotação, crop aleatório, escala, perspectiva
  • Fotométricas: brilho, contraste, saturação, ruído, blur
  • Mistura: MixUp (combina imagens e rótulos), CutMix (cola um recorte), RandAugment

Augmentation codifica invariâncias que você conhece do domínio. É conhecimento prévio injetado nos dados.

from torchvision.transforms import v2

train_tfm = v2.Compose([
    v2.RandomResizedCrop(224, scale=(0.7, 1.0)),
    v2.RandomHorizontalFlip(),
    v2.ColorJitter(0.2, 0.2, 0.2),
    v2.ToImage(),
    v2.ToDtype(torch.float32, scale=True),
    v2.Normalize([0.485, 0.456, 0.406],
                 [0.229, 0.224, 0.225]),
])
# validação/teste: SEM aleatoriedade
val_tfm = w.transforms()

Cuidado com o domínio

  • Flip horizontal em texto/dígitos: "b" vira "d"
  • Rotação 180° em dígitos: "6" vira "9"
  • ColorJitter em dermatologia: a cor é diagnóstica
  • Flip em raio-X de tórax: o coração muda de lado (dextrocardia é rara!)

Boas escolhas por domínio

  • Satélite: rotações de 90° e flips (não existe "pra cima")
  • Produtos: crop, escala, iluminação
  • Médico: pequenas rotações, elastic deform, brilho moderado
  • Para detecção/segmentação: transformar caixas e máscaras junto (v2 faz isso)
  • ImageNet = fotos RGB naturais, objeto centralizado
  • Domínios distantes: raio-X (1 canal, textura sutil), satélite multiespectral (13 bandas), microscopia, espectrogramas
  • Mesmo assim, o pré-treino costuma ajudar na convergência, mesmo quando ganha pouco em acurácia final (Raghu et al., 2019)
  • Alternativas: modelos pré-treinados no domínio (ex.: RadImageNet, SatMAE), self-supervised no seu próprio dado não rotulado

Leve para casa

  • Camadas iniciais são genéricas, finais são específicas
  • Poucos dados → congele mais. Muitos dados → fine-tune tudo com LR baixo
  • Mesma normalização do pré-treino
  • Augmentation = invariâncias do domínio. Nunca quebre o rótulo
  • Sem aleatoriedade na validação/teste
