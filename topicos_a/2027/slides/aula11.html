O paradoxo da acurácia

Fraude em 0,5% das transações: o modelo "nunca é fraude" tem 99,5% de acurácia e é inútil.

Qual erro custa mais?

Triagem de câncer: FN é grave → priorize revocação. Filtro de spam: FP (e-mail importante na lixeira) é grave → priorize precisão.

  • O modelo dá uma probabilidade; o limiar (0,5 por padrão) é uma decisão de negócio
  • Curva ROC: TPR × FPR variando o limiar. AUC-ROC = prob. de um + aleatório ter score maior que um − aleatório
  • Curva PR: precisão × revocação. Mais informativa com classes muito desbalanceadas (ROC fica otimista)
from sklearn.metrics import (classification_report,

Um modelo é calibrado se, entre as previsões com 80% de confiança, ~80% estão corretas.

  • Redes modernas costumam ser superconfiantes (Guo et al., 2017)
  • Reliability diagram: confiança média × acurácia por faixa
  • ECE (Expected Calibration Error): distância média à diagonal
  • Temperature scaling: divida os logits por $T > 1$ ajustado na validação. Um único parâmetro, e a acurácia não muda

Por que importa

Em medicina, crédito e carros autônomos, a confiança é usada para decidir quando chamar um humano. Confiança errada = decisão errada.

$p = \text{softmax}(\mathbf{z} / T)$

Mapa de saliência

$\left|\frac{\partial y_c}{\partial \mathbf{x}}\right|$: quais pixels mais mudam o score da classe $c$. Simples, mas ruidoso.

Grad-CAM (Selvaraju et al., 2017)

  1. Pegue os feature maps $A^k$ da última camada conv
  2. Peso de cada canal: $\alpha_k = \text{média}_{ij} \frac{\partial y_c}{\partial A^k_{ij}}$
  3. Mapa: $\text{ReLU}\left(\sum_k \alpha_k A^k\right)$, ampliado para o tamanho da imagem
# pip install grad-cam
from pytorch_grad_cam import GradCAM
from pytorch_grad_cam.utils.model_targets import (
    ClassifierOutputTarget)
from pytorch_grad_cam.utils.image import show_cam_on_image

cam = GradCAM(model=model,
              target_layers=[model.layer4[-1]])
heat = cam(input_tensor=x,
           targets=[ClassifierOutputTarget(281)])[0]
vis = show_cam_on_image(rgb_img, heat, use_rgb=True)

Cuidado: explicações também podem enganar. Adebayo et al. (2018) mostraram que alguns métodos de saliência produzem mapas parecidos até com pesos aleatórios. Use Grad-CAM como auditoria, não como prova.

Redes aprendem o atalho mais fácil que separa os dados, mesmo que não seja o que você queria.

  • "Lobo vs. husky": o modelo aprendeu neve no fundo (Ribeiro et al., 2016)
  • Raio-X de COVID: modelos aprendiam o hospital de origem (marcações, tipo de aparelho), não a doença
  • Câncer de pele: presença de régua na foto correlacionada com malignidade
  • ImageNet: CNNs têm viés para textura em vez de forma (Geirhos et al., 2019)

Como se defender

  • Grad-CAM em amostras aleatórias, especialmente nos acertos
  • Testar em dados de outra fonte (outro hospital, outra câmera)
  • Augmentation que quebra o atalho
  • Entender como o dataset foi coletado

Uma perturbação imperceptível muda a predição com alta confiança (Szegedy et al., 2014).

FGSM (Goodfellow et al., 2015)

$\mathbf{x}_{adv} = \mathbf{x} + \epsilon \cdot \text{sign}\left(\nabla_{\mathbf{x}} \mathcal{L}(\theta, \mathbf{x}, y)\right)$

Um passo de gradiente na entrada, para aumentar a perda. Com $\epsilon = 2/255$ a acurácia de uma ResNet pode cair a quase zero.

def fgsm(model, x, y, eps):
    x = x.clone().requires_grad_(True)
    loss = F.cross_entropy(model(x), y)
    loss.backward()
    return (x + eps * x.grad.sign()).clamp(0, 1).detach()

Defesas

  • Adversarial training (treinar com exemplos adversariais, ex.: PGD): a mais confiável, mas custa caro e reduz a acurácia limpa
  • Ataques físicos existem: adesivos em placas de trânsito

Distribution shift

  • Treino ≠ produção: câmera nova, iluminação, estação do ano, população diferente
  • ImageNet-C: ruído, blur, neve, JPEG → quedas grandes de acurácia
  • Monitorar a distribuição dos dados em produção é parte do trabalho

Ética

  • Gender Shades (Buolamwini & Gebru, 2018): sistemas comerciais com erro de até ~35% para mulheres de pele escura vs. <1% para homens de pele clara
  • Reconhecimento facial na segurança pública: prisões injustas documentadas no Brasil e nos EUA
  • Pergunte sempre: quem está (e quem não está) nos dados? Quem é afetado pelos erros?
