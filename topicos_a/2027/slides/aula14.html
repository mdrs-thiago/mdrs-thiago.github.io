Tradução; resumo

Não é só texto: séries temporais (demanda de energia, sensores, preços), áudio, DNA, logs de eventos. Tudo em que a ordem importa e o tamanho varia.

$\mathbf{h}_t = \tanh(\mathbf{W}_{hh}\mathbf{h}_{t-1} + \mathbf{W}_{xh}\mathbf{x}_t + \mathbf{b})$
  • $\mathbf{h}_t$: estado oculto, um resumo de tudo que foi lido até $t$
  • Os mesmos pesos em todos os passos (compartilhamento no tempo, como a conv compartilha no espaço)
  • Saída: $\mathbf{y}_t = \mathbf{W}_{hy}\mathbf{h}_t$, ou só o último $\mathbf{h}_T$ (many-to-one)

Backpropagation Through Time: desenrole a RNN em $T$ passos e aplique backprop normal.

$\frac{\partial \mathbf{h}_T}{\partial \mathbf{h}_1} = \prod_{t=2}^{T} \frac{\partial \mathbf{h}_t}{\partial \mathbf{h}_{t-1}} = \prod_{t=2}^{T} \text{diag}(\tanh'(\cdot))\,\mathbf{W}_{hh}$
  • Produto de $T-1$ matrizes: se a norma for < 1 → desaparece; se > 1 → explode
  • Na prática a RNN simples "lembra" ~10–20 passos

Exemplo

"O livro que eu comprei na feira de domingo passado, depois de muito pesquisar, é ótimo." Para concordar o verbo, o modelo precisa lembrar "livro" ~15 tokens depois.

Remédios

  • Explosão: gradient clipping
    clip_grad_norm_(model.parameters(), 1.0)
  • Desaparecimento: mudar a arquitetura → LSTM/GRU
$\mathbf{f}_t = \sigma(\mathbf{W}_f[\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_f)$   esquecimento
$\mathbf{i}_t = \sigma(\mathbf{W}_i[\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_i)$   entrada
$\tilde{\mathbf{c}}_t = \tanh(\mathbf{W}_c[\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_c)$   candidato
$\mathbf{c}_t = \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{c}}_t$   célula
$\mathbf{o}_t = \sigma(\mathbf{W}_o[\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_o)$   saída
$\mathbf{h}_t = \mathbf{o}_t \odot \tanh(\mathbf{c}_t)$
  • $\mathbf{c}_t$: a "esteira" de memória de longo prazo
  • Portas são sigmoides (0 a 1): quanto deixar passar
  • A atualização de $\mathbf{c}$ é aditiva: $\frac{\partial \mathbf{c}_t}{\partial \mathbf{c}_{t-1}} = \mathbf{f}_t$. Se $\mathbf{f} \approx 1$, o gradiente flui sem sumir
  • Mesma ideia da conexão residual (Aula 6)!

📓 Célula $\mathbf{c}$

O caderno onde você anota o que importa ao longo da leitura.

🧽 Esquecimento $\mathbf{f}$

Quanto apagar do caderno. Novo assunto na frase? Apaga o sujeito antigo.

✏️ Entrada $\mathbf{i}$

Quanto da informação nova vale anotar.

📢 Saída $\mathbf{o}$

Quanto do caderno usar agora para responder.

Parâmetros: 4 conjuntos de pesos (f, i, c̃, o) → uma LSTM tem ~4× os parâmetros de uma RNN simples do mesmo tamanho: $4(d_h(d_h + d_x) + d_h)$.

GRU (Cho et al., 2014)

Só 2 portas: reset e update. Funde célula e estado oculto. ~25% menos parâmetros que a LSTM e desempenho parecido na maioria das tarefas.

Bidirecional

Uma RNN lê da esquerda para a direita e outra da direita para a esquerda; os estados são concatenados. Ótimo para classificação e NER. Não serve para gerar texto (veria o futuro).

Empilhada

A sequência de $\mathbf{h}_t$ de uma camada vira a entrada da próxima. 2–3 camadas são comuns. Use dropout entre camadas.

lstm = nn.LSTM(input_size=128, hidden_size=256, num_layers=2,
               batch_first=True, bidirectional=True, dropout=0.3)
out, (h_n, c_n) = lstm(x)      # x: (B, T, 128)
# out: (B, T, 512)   h_n: (num_layers*2, B, 256)
  • Frases têm tamanhos diferentes → padding até o maior do batch
  • A LSTM não deve "ler" os pads: use pack_padded_sequence
  • Many-to-one: use o estado no último token real, não no último pad
  • Ordenar/agrupar por tamanho (bucketing) economiza computação
from torch.nn.utils.rnn import pack_padded_sequence

class LSTMClassifier(nn.Module):
    def __init__(self, V, d=128, h=256, n_cls=2):
        super().__init__()
        self.emb = nn.Embedding(V, d, padding_idx=0)
        self.lstm = nn.LSTM(d, h, batch_first=True,
                            bidirectional=True)
        self.fc = nn.Linear(2 * h, n_cls)

    def forward(self, ids, lengths):
        x = self.emb(ids)
        packed = pack_padded_sequence(x, lengths.cpu(),
            batch_first=True, enforce_sorted=False)
        _, (h_n, _) = self.lstm(packed)
        h = torch.cat([h_n[-2], h_n[-1]], dim=1)  # fwd+bwd
        return self.fc(h)
