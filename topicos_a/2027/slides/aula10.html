  • Diferenciar semântica, instância e panóptica
  • Explicar o papel das skip connections na U-Net
  • Escolher loss e métrica para classes desbalanceadas

Semântica

Cada pixel recebe uma classe. Duas pessoas lado a lado viram uma só mancha "pessoa".

Saída: $H \times W$ (ou $K \times H \times W$ logits).

Instância

Cada objeto contável recebe sua própria máscara. Pessoa 1, pessoa 2...

Saída: N máscaras binárias + classes.

Panóptica

Combina as duas: instâncias para "coisas" (pessoas, carros) e semântica para "fundo" (céu, estrada).

Aplicações: imagens médicas (tumores, órgãos), carros autônomos (pista, pedestres), agricultura (área plantada), satélite (desmatamento), edição de fotos (remover fundo).

  • Long et al. (2015): troca as camadas densas por convs → a rede aceita qualquer tamanho e produz um mapa de classes
  • Problema: o backbone reduz a resolução 32× → mapa grosseiro
  • Solução: upsampling de volta para $H \times W$

Formas de fazer upsampling

  • Interpolação bilinear (sem parâmetros)
  • Convolução transposta (ConvTranspose2d): upsampling aprendido
  • Upsample + conv (evita o artefato "tabuleiro de xadrez")
up = nn.ConvTranspose2d(64, 32, kernel_size=2,
                        stride=2)
x = torch.randn(1, 64, 16, 16)
print(up(x).shape)   # (1, 32, 32, 32)

# alternativa sem artefatos
up2 = nn.Sequential(
    nn.Upsample(scale_factor=2, mode='bilinear'),
    nn.Conv2d(64, 32, 3, padding=1))
  • Encoder: convs + pooling, captura o que (contexto)
  • Decoder: upsampling, recupera onde
  • Skip connections: concatenam features de alta resolução do encoder no decoder → bordas nítidas
  • Funciona com poucas imagens (o paper original usou 30!) + augmentation forte

Padrão dominante em imagens médicas, e o backbone dos modelos de difusão (Aula 21).

Losses

  • CE por pixel: a padrão, mas dominada pelo fundo quando o objeto é pequeno
  • Dice loss: $1 - \frac{2|P \cap G|}{|P| + |G|}$, robusta a desbalanceamento
  • Focal loss: reduz o peso dos pixels fáceis
  • Na prática: CE + Dice

Métricas

  • IoU / Jaccard por classe; mIoU = média entre classes
  • Dice / F1 = $\frac{2\,\text{IoU}}{1 + \text{IoU}}$
  • Acurácia de pixel engana: um tumor que ocupa 1% da imagem → 99% "prevendo tudo fundo"
def dice_loss(logits, target, eps=1e-6):   # binário
    p = torch.sigmoid(logits)
    inter = (p * target).sum(dim=(1, 2, 3))
    union = p.sum(dim=(1, 2, 3)) + target.sum(dim=(1, 2, 3))
    return 1 - ((2 * inter + eps) / (union + eps)).mean()
  • Faster R-CNN (Aula 9) + uma terceira cabeça que prevê uma máscara 28×28 para cada caixa detectada
  • RoIAlign: recorta as features de cada região sem arredondamento (essencial para máscaras precisas)
  • Detecção e segmentação de instância numa mesma rede
  • YOLO também tem versão de segmentação: yolo11n-seg.pt

Leve para casa

  • Semântica (classe por pixel) · instância (por objeto) · panóptica (ambos)
  • U-Net: encoder-decoder + skip connections = contexto + precisão
  • Desbalanceamento → Dice/focal; métricas IoU e Dice, não acurácia
  • Mask R-CNN = Faster R-CNN + cabeça de máscara
  • SAM: segmentação promptable zero-shot, mas sem classe
