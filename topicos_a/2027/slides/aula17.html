Entrada: $\mathbf{X} \in \mathbb{R}^{n \times d}$ ($n$ tokens, cada um um embedding de dimensão $d$).

$\mathbf{Q} = \mathbf{X}\mathbf{W}_Q,\quad \mathbf{K} = \mathbf{X}\mathbf{W}_K,\quad \mathbf{V} = \mathbf{X}\mathbf{W}_V$
$\text{Attention}(\mathbf{Q},\mathbf{K},\mathbf{V}) = \text{softmax}\!\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}}\right)\mathbf{V}$
  • $\mathbf{Q}\mathbf{K}^\top$: matriz $n \times n$ de afinidades entre todos os pares de tokens
  • Softmax por linha: cada token distribui 100% de atenção
  • Saída: cada token vira uma mistura dos values de todos

"self"

Q, K e V vêm da mesma sequência. Na frase "O banco estava cheio, então sentei no banco da praça", o segundo "banco" atende a "sentei" e "praça" e ganha um vetor diferente do primeiro.

→ Embeddings contextuais, resolvendo a limitação do word2vec (Aula 13).

  • Se os componentes de $\mathbf{q}$ e $\mathbf{k}$ têm média 0 e variância 1, então $\mathbf{q}^\top\mathbf{k} = \sum_{i=1}^{d_k} q_i k_i$ tem variância $d_k$
  • Com $d_k = 64$, os scores ficam na faixa de ±8 a ±16
  • Softmax de valores grandes → praticamente one-hot → gradientes ≈ 0 (saturação)
  • Dividir por $\sqrt{d_k}$ traz a variância de volta para 1
import torch, math
d = 64
q, k = torch.randn(10000, d), torch.randn(10000, d)
s = (q * k).sum(-1)
print(s.var())                 # ≈ 64
print((s / math.sqrt(d)).var())  # ≈ 1

x = torch.tensor([8., 1., -2.])
print(torch.softmax(x, 0))     # [0.9990, 0.0009, 0.0000]
print(torch.softmax(x / 8, 0)) # [0.59, 0.24, 0.17]
  • Uma única atenção mistura tudo em uma média só. Mas há vários tipos de relação: sintaxe, correferência, posição...
  • $h$ cabeças em paralelo, cada uma com seus próprios $\mathbf{W}_Q^i, \mathbf{W}_K^i, \mathbf{W}_V^i$ de dimensão $d_k = d/h$
  • Concatena as saídas e projeta: $\text{MHA} = \text{Concat}(\text{head}_1, \dots, \text{head}_h)\mathbf{W}_O$
  • Mesmo custo total de uma cabeça de dimensão $d$

Voita et al. (2019): algumas cabeças se especializam (posição relativa, dependência sintática, palavras raras); muitas podem ser podadas sem perda.

Parâmetros: 4 × 512 × 512 (+ bias) ≈ 1,05 M por camada de MHA.

  • Self-attention é invariante a permutações: "cão morde homem" = "homem morde cão" (como BoW!)
  • Solução: somar um vetor de posição ao embedding: $\mathbf{x}_t = \mathbf{e}_t + \mathbf{p}_t$
  • Senoidal (original): $p_{t,2i} = \sin(t/10000^{2i/d})$, $p_{t,2i+1} = \cos(\cdot)$, com frequências diferentes por dimensão
  • Aprendida (BERT, GPT-2): uma tabela nn.Embedding(max_len, d)
  • RoPE (Llama, Qwen): rotaciona Q e K conforme a posição → codifica distância relativa e extrapola melhor

Como os ponteiros de um relógio: cada dimensão gira em uma velocidade.

$\mathbf{X}' = \mathbf{X} + \text{MHA}(\text{LN}(\mathbf{X}))$
$\mathbf{Y} = \mathbf{X}' + \text{FFN}(\text{LN}(\mathbf{X}'))$
  • MHA: tokens trocam informação entre si
  • FFN: MLP aplicado a cada token separadamente ($d \to 4d \to d$, GELU). Guarda a maior parte dos parâmetros e, acredita-se, boa parte do "conhecimento"
  • Residual (Aula 6!) e LayerNorm (Aula 3) permitem empilhar dezenas de blocos
  • Pre-norm (LN antes) é mais estável que o post-norm original
class Block(nn.Module):
    def __init__(self, d=512, h=8, p=0.1):
        super().__init__()
        self.ln1, self.ln2 = nn.LayerNorm(d), nn.LayerNorm(d)
        self.attn = nn.MultiheadAttention(d, h, dropout=p,
                                          batch_first=True)
        self.ffn = nn.Sequential(
            nn.Linear(d, 4 * d), nn.GELU(),
            nn.Linear(4 * d, d), nn.Dropout(p))

    def forward(self, x, attn_mask=None, pad_mask=None):
        h = self.ln1(x)
        a, _ = self.attn(h, h, h, attn_mask=attn_mask,
                         key_padding_mask=pad_mask)
        x = x + a
        return x + self.ffn(self.ln2(x))

Encoder

Self-attention bidirecional: cada token vê todos. Bom para entender (classificação, NER). Ex.: BERT.

Decoder

Self-attention causal: o token $t$ só vê $\le t$. Necessário para gerar sem "colar" do futuro. Ex.: GPT.

Encoder-decoder

Decoder causal + cross-attention: Q do decoder, K/V do encoder. O original, para tradução. Ex.: T5.

n = 5

Duas máscaras diferentes: a causal (não ver o futuro) e a de padding (não ver os pads). Confundir as duas é um bug clássico.

  • A matriz de atenção tem $n \times n$ entradas por cabeça, por camada
  • Contexto de 4 mil tokens → 16 milhões de scores. Contexto de 128 mil → 16 bilhões
  • RNN: $O(n)$, mas sequencial. Transformer: $O(n^2)$, mas paralelo, e a GPU adora

Como os LLMs atuais lidam com isso

  • FlashAttention: mesmo resultado, sem materializar a matriz na memória
  • KV cache na geração (Aula 22)
  • Atenção esparsa, janelas deslizantes, modelos de espaço de estados (Mamba)

Leve para casa

  • $\text{softmax}(\mathbf{Q}\mathbf{K}^\top/\sqrt{d_k})\mathbf{V}$: tudo em multiplicação de matrizes
  • $\sqrt{d_k}$ evita a saturação do softmax
  • Multi-head = vários tipos de relação em paralelo
  • Posição precisa ser injetada (senoidal, aprendida, RoPE)
  • Bloco = MHA + FFN, com residual e LayerNorm
  • Máscara causal para gerar; custo $O(n^2)$
