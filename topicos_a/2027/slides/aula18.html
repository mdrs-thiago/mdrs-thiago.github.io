  1. Pré-treino (caro, uma vez): tarefa auto-supervisionada em bilhões de tokens, sem rótulos humanos. O rótulo vem do próprio texto
  2. Fine-tuning (barato, muitas vezes): ajustar para a sua tarefa com milhares de exemplos rotulados

É o transfer learning da Aula 7, agora para linguagem. ImageNet → seu dataset de imagens; Wikipedia + livros → seu dataset de texto.

Por que funcionou tão bem

  • Texto não rotulado é praticamente infinito
  • Prever palavras exige aprender sintaxe, semântica e conhecimento de mundo
  • Transformers paralelizam → dá para treinar em escala

Embeddings contextuais: ELMo (2018, com LSTMs) mostrou que o vetor de cada palavra deveria depender da frase. BERT e GPT levaram isso aos Transformers.

  • MLM (Masked Language Model): esconde 15% dos tokens e pede para a rede adivinhar, olhando os dois lados
  • Dos 15%: 80% viram [MASK], 10% um token aleatório, 10% ficam iguais (porque [MASK] não existe no fine-tuning)
  • NSP: a frase B segue a A? (RoBERTa mostrou que é dispensável)
  • Token [CLS] no início: seu vetor final resume a frase para classificação
  • BERT-base: 12 camadas, d=768, 12 cabeças, 110 M parâmetros

Uso ideal: entender texto: classificação, NER, busca semântica, QA extrativo.

  • Modelagem causal: prever o próximo token, vendo só o passado (máscara causal da Aula 17)
  • $\mathcal{L} = -\sum_t \log p(x_t \mid x_{<t})$: cada posição é um exemplo de treino
  • Gera texto autorregressivamente: prevê, anexa, repete
  • GPT-2 (2019, 1,5 B): geração fluente · GPT-3 (2020, 175 B): aprendizado in-context, resolve tarefas só com exemplos no prompt (few-shot)
  • Base de todos os LLMs atuais: GPT-4, Claude, Llama, Qwen, Gemini...

CNN vs. ViT

  • CNN tem vieses indutivos (localidade, equivariância): bom com poucos dados
  • ViT aprende tudo dos dados: perde para ResNet no ImageNet-1k puro, mas ganha com pré-treino em 300 M imagens
  • Hoje: ViTs são o backbone padrão de modelos multimodais

CLIP (Radford et al., 2021)

Dois encoders (imagem e texto) treinados em 400 M pares (imagem, legenda) para que pares corretos tenham cosseno alto (aprendizado contrastivo).

Resultado: classificação zero-shot ("uma foto de um {gato, cão, ...}") e a base do condicionamento por texto do Stable Diffusion (Aula 21).

Rodada 1

1BERT vê o contexto à esquerda e à direita de cada token.
2GPT é treinado com máscara causal.
3O ViT usa convoluções para extrair os patches de forma hierárquica.

Mentira: 3. Os patches passam por uma projeção linear; não há hierarquia convolucional.

Rodada 2

1No MLM, todos os tokens escolhidos são trocados por [MASK].
2No GPT, cada posição da sequência gera um exemplo de treino.
3T5 trata classificação como geração de texto.

Mentira: 1. São 80% [MASK], 10% aleatório e 10% iguais.

Rodada 3

1CLIP permite classificar imagens em classes nunca vistas no treino.
2Com poucos dados, um ViT do zero costuma superar uma ResNet.
3O vetor final do [CLS] é usado para classificação no BERT.

Mentira: 2. Sem vieses indutivos, o ViT precisa de muitos dados.

Leve para casa

  • Pré-treino auto-supervisionado + fine-tuning = transfer learning para texto
  • BERT (encoder, MLM): entender · GPT (decoder, causal): gerar · T5: texto → texto
  • Embeddings contextuais resolvem a polissemia
  • ViT: imagem = sequência de patches; precisa de muitos dados
  • CLIP: imagem e texto no mesmo espaço
