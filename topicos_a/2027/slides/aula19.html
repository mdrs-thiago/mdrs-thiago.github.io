Model cards (Mitchell et al., 2019)

Documentação do modelo: dados de treino, uso pretendido, limitações, vieses, métricas, licença. Um modelo sem card é sinal de alerta.

Licenças importam

Apache-2.0 e MIT: uso comercial livre. CC-BY-NC: não comercial. Licenças "abertas" de LLMs (Llama, Gemma) têm termos próprios. Leia antes de colocar em produção.

Use como baseline

Antes de treinar qualquer coisa, rode um pipeline zero-shot. Às vezes ele já resolve; senão, é o número a bater.

Sempre fixe o model=. O modelo padrão de uma tarefa pode mudar entre versões da biblioteca.

from transformers import (AutoTokenizer,
    AutoModelForSequenceClassification)

name = "neuralmind/bert-base-portuguese-cased"
tok = AutoTokenizer.from_pretrained(name)
model = AutoModelForSequenceClassification.from_pretrained(
    name, num_labels=2)     # cabeça nova, aleatória!

batch = tok(["Adorei!", "Péssimo atendimento, nunca mais."],
            padding=True, truncation=True, max_length=128,
            return_tensors="pt")
print(batch.keys())  # input_ids, token_type_ids, attention_mask
out = model(**batch)
print(out.logits.shape)  # (2, 2)
  • AutoTokenizer: o tokenizador exato do pré-treino (vocabulário, casing, tokens especiais)
  • attention_mask: a máscara de padding da Aula 17
  • AutoModelFor...: backbone pré-treinado + cabeça da tarefa (aqui, Linear sobre o [CLS])
  • O aviso "some weights were newly initialized" é esperado: é a cabeça nova
from datasets import load_dataset
import evaluate, numpy as np
from transformers import TrainingArguments, Trainer

ds = load_dataset("imdb")
def tokenize(b):
    return tok(b["text"], truncation=True, max_length=256)
ds = ds.map(tokenize, batched=True)

acc = evaluate.load("accuracy")
def metrics(p):
    preds = np.argmax(p.predictions, axis=-1)
    return acc.compute(predictions=preds,
                       references=p.label_ids)
args = TrainingArguments(
    output_dir="out", num_train_epochs=2,
    per_device_train_batch_size=16,
    learning_rate=2e-5, weight_decay=0.01,
    warmup_ratio=0.1, eval_strategy="epoch",
    save_strategy="epoch", load_best_model_at_end=True,
    fp16=True, report_to="none")

trainer = Trainer(model=model, args=args,
    train_dataset=ds["train"],
    eval_dataset=ds["test"],
    processing_class=tok,      # padding dinâmico
    compute_metrics=metrics)
trainer.train()

Hiperparâmetros típicos para BERT: LR 2e-5 a 5e-5, 2–4 épocas, warmup de 10%, AdamW. LR alto demais "esquece" o pré-treino (catastrophic forgetting).

(a) nº de parâmetros · (b) latência esperada em CPU · (c) adequação para classificar reviews em português (com fine-tuning)

CritérioOrdem (menor → maior)
(a) ParamsBERT-base-uncased (110 M) < DistilBERT-multi (~135 M, vocabulário grande) < XLM-R-base (~280 M) < BERTimbau-large (~335 M) < Qwen-0.5B (~494 M)
(b) LatênciaDistilBERT (6 camadas) < BERT-base (12) < XLM-R-base (12, vocabulário maior) < BERTimbau-large (24) < Qwen (24 camadas, e gera token a token)
(c) Adequação PTBERT-uncased (inglês) < DistilBERT-multi < Qwen (decoder, caro para classificar) < XLM-R < BERTimbau-large
DistilBERT multilíngue tem vocabulário grande (~119k), daí mais params que o BERT-base inglês, mas com só 6 camadas. Discutir que (b) e (c) admitem debate.

Leve para casa

  • Hub: modelos + datasets + Spaces; leia o model card e a licença
  • pipeline zero-shot = baseline grátis
  • Tokenizer do próprio modelo; cabeça nova é inicializada aleatoriamente
  • Trainer: LR ~2e-5, poucas épocas, warmup
  • Escolha por tarefa, idioma, tamanho, hardware e licença
