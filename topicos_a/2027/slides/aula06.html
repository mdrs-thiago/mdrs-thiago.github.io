ILSVRC

1,2 milhão de imagens de treino, 1000 classes. O erro humano estimado (top-5) é ~5%. Em 2015 as CNNs passaram dessa marca.

LeNet-5

  • Leitura de cheques (dígitos), ~60 mil parâmetros
  • Conv 5×5 → pool → conv 5×5 → pool → 3 densas
  • Já tinha o "padrão geral" da aula passada
  • Faltavam dados e poder de computação

AlexNet

  • 8 camadas, 60 milhões de parâmetros
  • ReLU: treino ~6× mais rápido que tanh
  • Dropout nas densas; data augmentation
  • Treinada em 2 GPUs GTX 580 por ~6 dias
  • Marco inicial da era do deep learning

Ingredientes que viraram padrão: dados grandes + GPU + ReLU + regularização.

VGG: simplicidade e profundidade

  • Só convs 3×3, empilhadas em blocos + max pool
  • Duas 3×3 = campo 5×5 com menos parâmetros ($2\cdot 9C^2$ vs. $25C^2$) e mais não linearidade
  • 16–19 camadas, ~138 M parâmetros (a maioria nas densas!)

Inception: largura multi-escala

  • Convs 1×1, 3×3, 5×5 e pool em paralelo, concatenadas
  • Conv 1×1 como gargalo: reduz canais antes das convs caras
  • 22 camadas com só ~7 M parâmetros
  • Troca as densas finais por Global Average Pooling

Conv 1×1 = uma camada densa aplicada em cada pixel, misturando canais. Aparece em quase todas as arquiteturas modernas.

Mais camadas deveriam ser pelo menos tão boas: as extras poderiam virar a identidade. Mas na prática:

  • Uma rede "plana" de 56 camadas tem erro de treino maior que uma de 20
  • Não é overfitting (o problema aparece no treino!)
  • É um problema de otimização: é difícil para várias camadas não lineares aprenderem a identidade
$\mathbf{y} = \mathcal{F}(\mathbf{x}) + \mathbf{x}$
  • O bloco aprende só o resíduo $\mathcal{F}(\mathbf{x}) = \mathcal{H}(\mathbf{x}) - \mathbf{x}$
  • Para virar identidade, basta $\mathcal{F} \to 0$ (pesos → 0): fácil
  • No backward: $\frac{\partial \mathbf{y}}{\partial \mathbf{x}} = \frac{\partial \mathcal{F}}{\partial \mathbf{x}} + \mathbf{I}$ → o gradiente tem uma "estrada" direta até as primeiras camadas
  • Se as dimensões mudam: projeção 1×1 no atalho
class BasicBlock(nn.Module):
    def __init__(self, c):
        super().__init__()
        self.f = nn.Sequential(
            nn.Conv2d(c, c, 3, padding=1, bias=False),
            nn.BatchNorm2d(c), nn.ReLU(),
            nn.Conv2d(c, c, 3, padding=1, bias=False),
            nn.BatchNorm2d(c),
        )
    def forward(self, x):
        return torch.relu(self.f(x) + x)   # atalho!

Acurácias dos pesos originais do torchvision (V1).

Bloco bottleneck

1×1 (reduz canais) → 3×3 → 1×1 (expande). Permite redes profundas com custo controlado. A ResNet-50 é o backbone "padrão" até hoje.

MobileNet (2017): depthwise separable

Conv padrão: $C_{out} C_{in} k^2$. Separável = depthwise ($C_{in}k^2$) + pointwise 1×1 ($C_{in}C_{out}$) → ~8–9× menos contas com $k=3$. Para celulares e embarcados.

EfficientNet (2019): compound scaling

Escalar profundidade, largura e resolução juntas, com proporções fixas, rende mais que escalar só uma. B0 (5,3 M) → B7 (66 M).

ViT (2020): sem convolução

Imagem em patches 16×16 → Transformer. Supera CNNs com muitos dados. Veremos no Bloco 5.

ConvNeXt (2022): a resposta das CNNs

ResNet "modernizada" com truques dos Transformers (kernels 7×7, LayerNorm, GELU) compete com ViTs.
