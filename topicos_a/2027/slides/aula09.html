Classificação

Saída: 1 rótulo. "gato"

Localização

Saída: 1 rótulo + 1 caixa. Um único objeto.

Detecção

Saída: N × (classe, confiança, caixa). N é desconhecido!

Bug nº 1 em detecção

Misturar formatos de caixa. Sempre visualize algumas anotações antes de treinar.

$\text{IoU}(A, B) = \frac{|A \cap B|}{|A \cup B|}$
  • 1 = caixas idênticas; 0 = sem sobreposição
  • Uma detecção é verdadeiro positivo se IoU com uma caixa real ≥ limiar (ex.: 0,5) e a classe estiver certa
def iou(a, b):  # xyxy
    x1, y1 = max(a[0], b[0]), max(a[1], b[1])
    x2, y2 = min(a[2], b[2]), min(a[3], b[3])
    inter = max(0, x2 - x1) * max(0, y2 - y1)
    area = lambda r: (r[2]-r[0]) * (r[3]-r[1])
    return inter / (area(a) + area(b) - inter)

Real 120×100, predita 130×100, interseção 60×70 → IoU = 4200 / (12000+13000−4200) ≈ 0,20

Detectores geram muitas caixas sobrepostas para o mesmo objeto. O NMS limpa:

  1. Ordene as caixas por confiança
  2. Pegue a de maior confiança e guarde
  3. Remova as restantes com IoU > limiar (ex.: 0,45) em relação a ela
  4. Repita até acabar
from torchvision.ops import nms
keep = nms(boxes, scores, iou_threshold=0.45)

Limitações

  • Objetos realmente sobrepostos (multidão) podem ser suprimidos
  • Limiar é hiperparâmetro
  • Detectores recentes (DETR, YOLOv10) eliminam o NMS com atribuição um-para-um no treino
  • Para cada classe: ordene as detecções por confiança, calcule precisão e revocação em cada corte → curva PR
  • AP = área sob a curva PR daquela classe
  • mAP = média do AP entre as classes
  • mAP@0.5: TP com IoU ≥ 0,5 (métrica do PASCAL VOC)
  • mAP@0.5:0.95: média em limiares de 0,5 a 0,95 (passo 0,05). Métrica do COCO, que premia caixas precisas

Para lembrar

mAP@0.5:0.95 ≤ mAP@0.5, sempre: os limiares mais altos só podem diminuir os acertos.

YOLO11n no COCO: mAP@0.5:0.95 ≈ 39,5.

Anchors

Caixas-modelo de vários tamanhos e proporções em cada posição do feature map. A rede prevê ajustes (offsets) em relação a elas.

Dois estágios: alta precisão, especialmente em objetos pequenos. Base do Mask R-CNN (próxima aula).

  • YOLOv1 (Redmon et al., 2016): divide a imagem em uma grade S×S; cada célula prevê caixas + confiança + classes, numa única passada
  • Detecção vira regressão → 45+ fps já em 2016
  • Evolução: anchors (v2–v5), backbones melhores, multi-escala (FPN), anchor-free (v8+), sem NMS (v10)
  • Hoje: família mantida pela Ultralytics (YOLOv8, YOLO11...), tamanhos n/s/m/l/x

Trade-off velocidade × acurácia: YOLO11n roda em CPU/celular; YOLO11x é mais preciso mas ~10× mais pesado. Escolha pelo requisito de latência.

COCO

80 classes do dia a dia (pessoa, carro, cachorro, xícara...). Se a sua classe não está lá, o modelo pré-treinado não vai detectá-la: precisa de fine-tuning.

Dataset YAML

Caminhos para images/ e labels/ + lista de nomes de classes. Um .txt por imagem com classe xc yc w h.

Regras 3 × 4 min

Em grupos. Em cada rodada, encontrem a afirmação falsa e expliquem o erro. Mentira certa = 1 ponto; explicação correta = +1.

Rodada 1

1O NMS remove caixas com IoU alto em relação à caixa de maior confiança.
2mAP@0.5:0.95 é sempre maior ou igual a mAP@0.5.
3YOLO faz a detecção em uma única passada pela rede.

Mentira: 2. Limiares mais exigentes só reduzem os acertos.

Rodada 2

1No Faster R-CNN, as propostas de região são geradas por uma rede (RPN).
2IoU = 0,5 significa que metade da caixa predita está dentro da real.
3Um YOLO treinado no COCO não detecta classes fora das 80 do COCO.

Mentira: 2. IoU é interseção/união, não fração de uma caixa.

Rodada 3

1No formato YOLO, as coordenadas são normalizadas entre 0 e 1.
2Anchors são caixas-modelo; a rede prevê ajustes em relação a elas.
3Detectores de um estágio são sempre menos precisos que os de dois.

Mentira: 3. YOLOs modernos superam o Faster R-CNN original em mAP.

Leve para casa

  • Detecção = N × (classe, confiança, caixa)
  • IoU mede sobreposição; NMS remove duplicatas
  • mAP@0.5 vs. mAP@0.5:0.95 (precisão de localização)
  • Dois estágios (RPN + classificação) vs. um estágio (YOLO)
  • Classe fora do COCO → fine-tuning
