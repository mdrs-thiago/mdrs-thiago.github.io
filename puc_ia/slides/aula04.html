O que é low-code / no-code?

No-Code

Zero código. Tudo por arrastar-e-soltar, condicionais e integrações prontas (ex.: Zapier).

Low-Code

Interface visual, mas permite código customizado nos pontos onde falta flexibilidade (ex.: n8n, Make).

Diferença que importa pra IA: quem não programa consegue prototipar um agente sozinho — e um dev consegue ir além, com nós de código quando precisar.

De agentes de código a low-code

Dá pra programar um agente ReAct em Python do zero. Mas, pra prototipar rápido — e pra quem não é dev — ferramentas low-code de automação conectam LLMs a APIs visualmente, sem escrever o loop manualmente.

Hoje: n8n — automação visual de workflows (nós conectados por setas), com suporte nativo a chamadas de LLM.

Por que n8n, e não Zapier ou Make?

FerramentaModeloPonto forte pra IA
Zapier / MakeSaaS fechado, pago por execuçãoCatálogo enorme de integrações prontas
n8nOpen-source, self-hosted (de graça na sua máquina)Nó de código embutido + chamadas de LLM sem limite de execuções pagas

Pro projeto integrado: sem custo por execução e sem depender de um serviço de terceiros pra rodar seu MVP.

Anatomia de um workflow no n8n

Trigger

O que inicia o fluxo: um Webhook, um horário agendado, um formulário.

Processamento

Nós de HTTP Request, código, condicionais — incluindo chamar um LLM.

Saída

Responder o webhook, enviar e-mail, escrever numa planilha.

Um nó visual, a mesma chamada de sempre

O nó HTTP Request do n8n não faz mágica — ele monta exatamente a chamada que você já viu na aula passada:

POST http://localhost:11434/api/generate
{
  "model": "llama3.2",
  "prompt": "{{ $json.pergunta }}",
  "stream": false
}

A diferença é só a interface: parâmetros preenchidos em um formulário, não em código.

Vantagens e limites do low-code

Vantagens

Prototipagem rápida, visual e auditável — qualquer pessoa do time entende o fluxo olhando pra ele.

Limites

Menos controle fino que código puro; workflows exportados como JSON são mais difíceis de revisar num Pull Request do que um .py.

Por isso, na Aula 06 (Git), workflows exportados também entram no repositório — versionados como qualquer outro artefato do projeto.

Quest: Montar um fluxo no n8n

  1. Suba o n8n localmente: puc_ia/n8n/setup.sh (detecta Docker ou usa npx n8n)
  2. Um workflow de exemplo já vem importado: Webhook → chama o LLM local → responde
  3. Edite o workflow: troque o prompt, adicione um passo extra (ex.: outro nó HTTP, uma condicional)
  4. Teste enviando uma requisição pro webhook e veja a resposta do seu agente
