Rodar uma LLM local

Versão completa: além de conversar pelo terminal, chame o modelo via API HTTP — a mesma chamada que o n8n faz por dentro de um workflow.

Passo a passo

  1. Instale o Ollama ou LM Studio e baixe um modelo (ex.: ollama pull llama3.2).
  2. Converse com ele pelo terminal: ollama run llama3.2.
  3. Chame a API local: curl http://localhost:11434/api/generate -d '{"model":"llama3.2","prompt":"...","stream":false}'
