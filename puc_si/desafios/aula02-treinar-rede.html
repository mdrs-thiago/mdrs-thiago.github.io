Sua primeira rede neural

No Lab 02 você construiu uma regressão inteira na mão, sem nn.Module nem optimizer. Agora faça o caminho "de verdade": monte, treine e observe uma rede neural pequena usando as ferramentas que a aula apresentou.

Passo a passo

  1. Abra um notebook (Google Colab ou Jupyter local).
  2. Crie um dataset sintético pequeno (ex.: y = 2x + 1 com um pouco de ruído, ou um problema de classificação simples como XOR).
  3. Defina um modelo com nn.Module, usando pelo menos uma camada oculta com ativação (nn.Linear + nn.ReLU).
  4. Escolha uma loss (nn.MSELoss para regressão, ou nn.CrossEntropyLoss para classificação) e um otimizador (SGD ou Adam).
  5. Treine por algumas dezenas/centenas de épocas, imprimindo a loss a cada N épocas.
  6. Confira: a loss caiu de forma consistente? Em algum ponto ela estabilizou?
