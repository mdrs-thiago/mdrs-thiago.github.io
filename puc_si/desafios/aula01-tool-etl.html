Uma ferramenta de dados para um agente

Diferente do quiz, aqui você não só escreve a função — você escreve o código que conversa com o agente: monta o pedido HTTP pro Ollama, lê a chamada de ferramenta que o modelo decidiu fazer, roda sua função de verdade, e devolve o resultado real pro modelo. Nada disso acontece escondido — é tudo Python, na sua tela, que você testa rodando você mesmo.

Você precisa do Ollama rodando localmente com CORS liberado, e um modelo com suporte a tool calling baixado. Veja o guia completo — tem o passo a passo de instalação, um botão pra testar a conexão, e o formato exato dos pedidos e respostas que você vai precisar pra completar o código abaixo.
