Indexação e Fatiamento (Slicing)

Regras fundamentais

  • Índices positivos: 0, 1, 2, ... (a partir do início)
  • Índices negativos: -1 (último), -2 (penúltimo), ...
  • Fatiamento: [start:stop:step] — stop é exclusivo
  • Omitir start: começa do 0. Omitir stop: vai até o fim.
  • 2D: arr[linha, coluna] — vírgula separa eixos
  • Toda dimensão: : — ex: arr[:, 2] = coluna 2 inteira
⚠️ View, não cópia! Slicing retorna uma view (janela no mesmo bloco de memória). Modificar a view modifica o original! Use .copy() quando precisar de independência.
Truques úteis: [::-1] inverte. [::2] pega pares. [1::2] pega ímpares.

Broadcasting — A "Mágica" do NumPy

Regras do Broadcasting

  1. Shapes são comparados da direita para a esquerda
  2. Dimensões são compatíveis se forem iguais ou se uma delas for 1
  3. Dimensões ausentes equivalem a 1
  4. Arrays são "expandidos" virtualmente (sem copiar dados)

Exemplos de compatibilidade

Shape AShape BResultado
(3,4)(4,)✅ (3,4)
(3,4)(1,4)✅ (3,4)
(3,1)(1,4)✅ (3,4)
(3,4)(3,)❌ Erro
(3,4,5)(4,5)✅ (3,4,5)
🎯 Uso em DS/ML Normalização por coluna, subtração de média, adição de bias em redes neurais — tudo usa broadcasting!

Filtragem de Linhas — Boolean Mask e query()

Formas de filtrar

  • Boolean mask: df[df['col'] > val]
  • AND: (cond1) & (cond2)
  • OR: (cond1) | (cond2)
  • NOT: ~(cond)
  • isin(): df[df['col'].isin([a, b])]
  • between(): df[df['col'].between(a, b)]
  • str.contains(): busca texto com regex
  • query(): string tipo SQL — mais legível
⚠️ Parênteses são obrigatórios! (df['a']>1) & (df['b']<5)
Sem parênteses o Python avalia errado por precedência de operadores.
query() aceita variáveis com @: df.query('sal > @limite')

agg() vs transform()

agg() → reduz (1 valor por grupo). transform() → mantém o shape original, broadcasting o resultado pelo grupo.

Caso clássico "Salário relativo à média do departamento" — requer transform para criar coluna com mesmo índice que o DF original.

Matriz de Correlação — Heatmap

Correlação de Pearson

Mede a relação linear entre variáveis numéricas. Varia de -1 (inversa perfeita) a +1 (direta perfeita). Zero = sem correlação linear.

df.corr() # toda a matriz
df[c1].corr(df[c2]) # entre duas cols
🎯 EDA Obrigatória em ML Features muito correlacionadas causam multicolinearidade em modelos lineares e árvores. Identificar antes de modelar!

Checklist de EDA

  • Shape, dtypes, nulos
  • Distribuições (hist, boxplot)
  • Correlações entre features
  • Outliers
  • Relação features → target

Boas Práticas

Boas Práticas e Performance

NumPy

  • Prefira operações vetorizadas — nunca use loop Python em arrays grandes
  • Use float32 em ML para economizar memória da GPU
  • Evite cópias desnecessárias — use views e out= parameter
  • Use np.random.default_rng(seed) — API moderna e mais rápida
  • np.einsum para operações tensorial complexas

Pandas

  • Use dtype='category' para colunas com poucos valores → até 10× menos memória
  • Leia CSV com dtype= explícito para evitar inferência lenta
  • Evite df.iterrows() — é o caminho mais lento possível
  • Prefira df.assign() a df[col] = para código encadeável
  • Use pd.read_csv(..., chunksize=) para arquivos grandes
  • Método eval() para expressões complexas — usa menos memória
