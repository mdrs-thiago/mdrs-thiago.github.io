O que é um Tensor?

Matematicamente, é uma generalização:

  • Escalar (0-d): Um número.
  • Vetor (1-d): Uma lista.
  • Matriz (2-d): Uma tabela.
  • Tensor (n-d): Volume ou Hiper-volume.
Por que usar Tensores?
Porque GPUs amam processar blocos massivos de números em paralelo. 

import torch

# Escalar
s = torch.tensor(42)

# Vetor
v = torch.tensor([1.0, 2.0, 3.0])

# Matriz 2x3
M = torch.randn(2, 3) 

# Tensor 3D (ex: Imagem RGB 28x28)
img = torch.randn(3, 28, 28)

Operações com Tensores

Muito similar ao NumPy, mas com "superpoderes".

Matemática Básica


x = torch.ones(2, 2)
y = torch.ones(2, 2) * 3

# Soma (Element-wise)
z = x + y  # [[4, 4], [4, 4]]

# Multiplicação Matricial
a = torch.randn(2, 5) # 2x5
b = torch.randn(5, 3) # 5x3
c = torch.matmul(a, b) # 2x3 (ou a @ b)

Reshape & View


x = torch.randn(4, 4) # 16 elementos

y = x.view(16)      # Vetor de 16
z = x.view(-1, 8)   # Matriz 2x8

# "Inferir" dimensão: -1 manda o PyTorch calcular

Aceleração via GPU (CUDA)

A "killer feature" do Deep Learning.

Regra de Ouro: Você só pode operar tensores que estão no mesmo dispositivo. 

# Verificar se tem GPU
device = "cuda" if torch.cuda.is_available() else "cpu"

x = torch.randn(2, 2).to(device)
y = torch.randn(2, 2).to(device)

z = x + y # Executado na placa de vídeo!
(Se tentar somar GPU + CPU, o PyTorch vai lançar um erro Runtime.)

Autograd: Diferenciação Automática

É aqui que a "mágica" acontece. Nós construímos o grafo de computação, e o PyTorch calcula as derivadas (gradientes) sozinho.


x = torch.tensor(2.0, requires_grad=True)
y = torch.tensor(3.0, requires_grad=True)

# Função: f = x^2 * y + y
f = (x**2) * y + y

# Backpropagation (Derivar tudo!)
f.backward()

# Ver os gradientes (df/dx e df/dy)
print(x.grad) # df/dx = 2xy = 12
print(y.grad) # df/dy = x^2 + 1 = 5

Grafo Computacional

Otimização (Gradient Descent)

Em Deep Learning, queremos encontrar o mínimo de uma função de erro.

$$ w_{novo} = w_{velho} - \text{learning\_rate} \times \frac{\partial \text{Erro}}{\partial w} $$

O x.grad que calculamos no slide anterior é exatamente esse $\frac{\partial \text{Erro}}{\partial w}$. É assim que as redes "aprendem".
