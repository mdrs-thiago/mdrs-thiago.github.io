Orientação a Objetos (OOP)

Fundamental para entender PyTorch (onde tudo é uma Classe).

Classes e Objetos


class NeuroBot:
    # Construtor (__init__)
    def __init__(self, name, version):
        self.name = name
        self.version = version

    # Método
    def say_hello(self):
        return f"I am {self.name} v{self.version}"

bot = NeuroBot("GPT", 4)

1. NumPy: A Base Numérica

Python puro é lento para matemática pesada. NumPy resolve isso com Arrays em C.

Arrays N-Dimensionais


    import numpy as np

    # Vetor (1D)
    v = np.array([1, 2, 3])
    
    # Matriz (2D)
    m = np.array([[1, 2], [3, 4]])
    
    # Operações Vetorizadas (RÁPIDO!)
    print(v * 2) # [2, 4, 6]
Broadcasting: NumPy expande arrays menores para casar com maiores.
[1, 2] + 10 = [11, 12]
