1. Por que Python?

O Python domina absolutamente o panorama da Inteligência Artificial. Mas por que motivo uma linguagem conhecida por ser "lenta" é a líder no processamento mais pesado do mundo?

A "Linguagem Cola"

  • O Paradoxo: O Python puro possui o GIL (Global Interpreter Lock), o que o torna terrível para paralelismo.
  • A Solução: Bibliotecas como NumPy, PyTorch e TensorFlow são escritas em C/C++ e CUDA sob o capô.
  • O Python atua apenas como uma API elegante (uma "cola") que orquestra a execução rápida em hardware de baixo nível.
Ecossistema Imbatível: Onde quer que vá (Investigação, Finanças, Big Tech), o standard é Python.

2. O Ambiente de Desenvolvimento

A regra número 1 do Engenheiro de Dados: Nunca instale pacotes no Python global do seu sistema. Isso leva ao infame "Dependency Hell".

Ambientes Virtuais (vEnvs)

Um ambiente virtual é uma pasta isolada que contém o seu próprio executável Python e a sua própria coleção de bibliotecas (separada de outros projetos).

pip vs Conda

  • pip/venv: Padrão do Python. Leve e rápido. Ideal para a maioria dos projetos.
  • Conda (Anaconda): Instala binários pesados e dependências externas (como bibliotecas C++ da Nvidia/CUDA). Padrão em laboratórios científicos.
# 1. Criar um ambiente isolado
python -m venv .venv

# 2. Ativar o ambiente
# No Windows:
.venv\Scripts\activate
# No Mac/Linux:
source .venv/bin/activate

# 3. Instalar o Stack Base de IA
pip install numpy pandas matplotlib 
pip install torch torchvision

# 4. Congelar dependências num ficheiro
pip freeze > requirements.txt

3. Orientação a Objetos (OOP)

O paradigma OOP é obrigatório em IA. No PyTorch, cada Rede Neuronal e cada Dataset é uma Classe.

Classes e Objetos

  • Classe: A planta/molde de um objeto.
  • __init__: O construtor. É aqui que definimos o "estado" (variáveis) do objeto quando ele nasce.
  • self: A referência ao próprio objeto. Deve ser o primeiro parâmetro de qualquer método dentro da classe.
class NeuroBot:
    # O Construtor
    def __init__(self, nome, versao):
        self.nome = nome     # Atributo
        self.versao = versao # Atributo

    # O Método (Ação)
    def saudar(self):
        return f"Olá, sou o {self.nome} v{self.versao}"

# Instanciar o objeto
bot = NeuroBot("GPT", 4)
print(bot.saudar()) 
# Output: "Olá, sou o GPT v4"

Herança e Métodos Mágicos

Em frameworks de Deep Learning, nós herdamos classes pré-construídas para ganhar os seus superpoderes e sobrescrevemos Dunder Methods (Double Underscore).

Herança (PyTorch Module)

import torch.nn as nn

# A nossa rede herda de nn.Module
class MinhaRede(nn.Module):
    def __init__(self):
        # Obriga a iniciar a classe Mãe!
        super().__init__()
        self.layer = nn.Linear(10, 2)
        
    def forward(self, x):
        return self.layer(x)

Dunder Methods (Dataset)

from torch.utils.data import Dataset

class MeuDataset(Dataset):
    def __init__(self, dados):
        self.dados = dados
        
    # Permite usar len(dataset)
    def __len__(self):
        return len(self.dados)
        
    # Permite indexação: dataset[0]
    def __getitem__(self, idx):
        return self.dados[idx]

4. NumPy: A Base Numérica

O NumPy é o motor matemático da ciência de dados. Ele introduz o objeto ndarray (Array N-Dimensional).

Vetorização vs For-Loops

Regra de Ouro: Nunca use ciclos FOR para matemática em Python.

Operações no NumPy são "vetorizadas", o que significa que são passadas diretamente para a linguagem C em lote, sendo até 100x mais rápidas que as listas nativas do Python.

O formato de Tensores do PyTorch (torch.Tensor) é um clone quase exato do numpy.array, mas com a capacidade extra de correr em GPUs. 
import numpy as np

# Vetor (1D)
v = np.array([1, 2, 3])

# Matriz (2D)
m = np.array([[1, 2], [3, 4]])

# Vetorização (Rápido e limpo)
# Multiplica todos os elementos por 2
resultado = v * 2 
print(resultado) # [2, 4, 6]

# Operações Estatísticas
media = np.mean(m)
soma_colunas = np.sum(m, axis=0)

O Poder do "Broadcasting"

O Broadcasting é o mecanismo que permite ao NumPy realizar operações matemáticas entre arrays de tamanhos diferentes, expandindo-os virtualmente na memória.

Se tentarmos somar uma Matriz $3 \times 3$ com um Vetor $1 \times 3$, a matemática clássica daria erro.

O NumPy percebe a intenção e "estica" (broadcast) o vetor pelas 3 linhas da matriz automaticamente para executar a soma, poupando código e memória (ele não duplica os dados fisicamente).

matriz = np.ones((3, 3))
vetor = np.array([1, 2, 3])

# O vetor é somado a cada linha!
resultado = matriz + vetor

5. Pandas: "O Excel com Esteroides"

O pandas é a ferramenta essencial para o ETL (Extração, Transformação e Carga) de dados tubulares estruturados. Baseia-se no objeto DataFrame.

Análise Exploratória de Dados (EDA).

import pandas as pd

# 1. Carregar dados de um ficheiro
df = pd.read_csv("dados_casas.csv")

# 2. Explorar
print(df.head())     # 5 primeiras linhas
print(df.describe()) # Estatísticas

# 3. Limpar (Data Cleaning)
df = df.dropna()         # Remove linhas com N/A
df['preco'].fillna(0)    # Preenche vazios com 0

# 4. Filtrar (SQL-like)
casas_caras = df[ df['preco'] > 1000000 ]
