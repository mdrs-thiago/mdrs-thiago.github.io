Regra #1: 80% do tempo de um projeto de IA é gasto preparando dados.

ETL (Extract, Transform, Load)

1. Extract

Tirar o dado de onde ele nasce.

  • Web Scraping (BeautifulSoup).
  • SQL (`SELECT *`).
  • Sensores IoT.

2. Transform

Onde a mágica acontece.

  • Normalização (0 a 1).
  • Limpeza (Remover nulos).
  • Feature Engineering.

3. Load

Salvar para consumo.

  • Data Warehouse.
  • Arquivo `.parquet` (eficiência).

Qualidade de Dados

O que define um dado "bom"?

  • Completude: Faltam valores? (Nulls/NaN).
  • Unicidade: Existem duplicatas?
  • Consistência: O campo "Idade" tem alguém com 200 anos? (Outliers).
  • Validade: O email tem `@`?

import pandas as pd

df = pd.read_csv("raw_data.csv")

# Checar nulos
print(df.isnull().sum())

# Checar duplicatas
print(df.duplicated().sum())

# Remover lixo
df_clean = df.dropna().drop_duplicates()

Viés (Bias)

Seus dados refletem a realidade ou uma distorção dela?

Exemplo Clássico: Amazon Recruitment AI (2018)

A Amazon treinou uma IA para filtrar currículos.

Problema: Os dados históricos eram majoritariamente de homens.

Resultado: A IA aprendeu a penalizar a palavra "Women's" (ex: "Women's Chess Club") e rejeitava candidatas.

Tipos Comuns:
  • Selection Bias: O dataset não é representativo da população.
  • Historical Bias: Preconceitos existentes no mundo real.
