Microcontroladores e controle em tempo real

Da última aula

O Raspberry Pi é um computador completo — roda Linux, Python, multitarefa. O Arduino é o oposto: um microcontrolador, sem sistema operacional, que roda um único programa em loop, sem parar.

Trocamos flexibilidade por previsibilidade: o Arduino não trava, não "engasga" rodando outra coisa — ideal pra controle em tempo real.

Anatomia de um Sketch

Todo programa Arduino ("sketch") tem exatamente duas funções:

void setup() {
  // roda uma vez, ao ligar
  Serial.begin(9600);
  pinMode(13, OUTPUT);
}

void loop() {
  // roda para sempre, em loop
  digitalWrite(13, HIGH);
  delay(500);
  digitalWrite(13, LOW);
  delay(500);
}

Lendo um sensor analógico

void loop() {
  int leitura = analogRead(A0);       // 0 a 1023
  float tensao = leitura * (5.0 / 1023.0);
  Serial.println(tensao);             // envia pro computador via USB
  delay(200);
}

Um potenciômetro, um LDR (sensor de luz) ou um sensor de umidade de solo — todos entram por uma porta analógica assim.

Arduino + Raspberry Pi: a ponte serial

Na prática, os dois trabalham juntos: o Arduino cuida do sensor em tempo real, e envia a leitura por Serial (USB) pro Pi, que roda a lógica de decisão em Python.

Arduino (C++)

Serial.println(leitura);

Raspberry Pi (Python)

import serial
porta = serial.Serial('/dev/ttyUSB0', 9600)
leitura = porta.readline()
É a mesma ideia do Lab 07: leitura → decisão → ação. Só que agora o "sentir" e o "pensar" ficam em placas diferentes.
